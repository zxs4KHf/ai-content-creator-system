## 一、总判断

参考 UP 的效果不能靠“换一个更强视频模型”稳定复刻。公开证据更符合下面这条链：

`长期角色/场景资产 → 服装和年龄变体 → 绑定/动作/表情/口型 → 摄影机/灯光 → 渲染 → 后期 → AI 辅助声音或其他环节`

AI 的价值是降低某些局部成本，不是替代整套资产工程。要稳定达到相近水平，真正的护城河是：

- 角色资产能跨集复用；
- 动作、表情和镜头可以编辑而非重新抽卡；
- 每个服装/年龄版本都能回归测试；
- 声音具备可持续授权；
- 后期把镜头、对白、音效和节奏统一起来。

## 二、四条可迁移结论

1. **参考的是方法，不是 IP。** 对本项目最有价值的是资产版本化、表演节拍、服饰变化、年龄变化、两人分工和系列化复用，不是复刻《鸣潮》角色、原声或剧情。
2. **故事会经典故事先走 2D/2.5D，验证内容再投入 3D。** 当前账号还没有发布数据，直接建设完整 3D 角色线会把内容验证和技术建设绑死。
3. **声音先买效果，再决定是否本地化。** 十元级 MiniMax 原创 Voice Design 能快速判断“更自然的女声是否显著提升成片”；若听感确实有提升，再投入本地 Qwen/VoxCPM 环境。
4. **生成式视频只升级英雄镜。** 当前 8GB 显卡可以研究 FramePack/LTX 低显存路线，但速度、漂移和返工不适合作为全片默认。

## 四、对故事会经典故事的落地

### 当前轮：不越过人工 G1/G2/G3

- GS01–GS06 仍停在 G1；AI 不代替用户选择故事。
- 第一个故事 A/B/C 仍停在 G3；本轮研究不暗中替换成片。
- 语音仍是影子实验；无 Key、预算或模型下载授权时不执行。

### G1 选题新增三个可视化字段

- `REUSE_POTENTIAL`：角色/场景/道具能否跨集复用；
- `ASSET_TIER`：静帧 / 2D 绑定 / 3D / 随机生成；
- `HERO_MOTION`：最多 1–3 个必须运动的镜头及失败回退。

### G2 资产包

在现有脚本、六帧因果板和漫画布局之外，若选题进入角色动画试点，再附：

- 角色版本：`CHARACTER_ID + AGE_VARIANT + OUTFIT_ID`；
- 表情：起点、峰值、落稳；
- 动作：`TRIGGER → PERCEIVE → PREPARE → EXECUTE → SETTLE`；
- 摄影机：起点、路径、目标、速度、停点；
- 资产权利与回退方案；
- 预估新增资产、人时和显存档位。

### G2 → G3

`真实旁白 → 口型/字幕时间轴 → 静态 animatic → 确定性全片 → 1–3 英雄镜 → 五点帧/接触 QA → 声画终审`

随机动态镜没有明显提升、出现身份/服装/手部/道具/背景漂移，或同配置连续失败两次，立即回退。

## 六、成本真相

- MiniMax 正式语音非常便宜：HD 3.5 元/万字符；当前 374 计费字符基准约 0.1309 元。贵的是原创音色首次启用 9.9 元与人工挑选，而不是单条生成。[官方价格](https://platform.minimaxi.com/docs/guides/pricing-paygo)
- 本地模型不是“免费”：下载、环境、显存冲突、慢速推理、失败清理和维护都要计入人时。
- 3D 管线最贵的是第一次角色/服装/绑定；系列越长，复用价值越大。
- 随机视频单次看似便宜，但失败率会把人时和算力放大；没有确定性回退就无法做矩阵生产。

## 七、项目决策建议

1. **近期继续故事会原创经典短篇 + 漫画解说，不等待 3D。** 先取得真实发布数据。
2. **首个声音付费实验优先 MiniMax 原创音色设计，不做克隆。** 它最接近用户给出的听感参考，又不需要 GPU 环境。
3. **本地只保留两个候选：Qwen3-TTS 1.7B 和 VoxCPM2。** 不同时下载，不为“模型收藏”消耗磁盘与维护成本。
4. **建立 K12/T14 的资产与实验合同。** 以后任何角色动画必须说明资产来源、版本、动作/表情/口型、镜头、资源预算和回退。
5. **若以后做游戏二创，先取得官方/资产/声音的权利记录。** 没有权利闭环时，仅把它当方法研究，不纳入账号矩阵的商业默认。
