# 调研：MiniMax 与参考声音（2026-07-28）

- 目标：以最低合法成本逼近参考 UP 主旁白的自然度、节奏和成片完成度，不复刻、识别或训练其声纹。
- 参考视频：[《轻松复刻！爆肝揭秘万粉 UP 主是如何炼成的，我的 AI 早报“生产线”大公开。》](https://www.bilibili.com/video/BV1B82DBdEdP/)
- 证据边界：MiniMax 能力、价格和条款只采用 MiniMax/阿里云官方资料；参考 UP 的工具和参数只采用作者本人在公开视频与评论区的公开说明。
- 操作边界：本轮没有下载或转录视频，没有下载模型、注册账号、调用 API、上传参考音或付费。
- 标签：`[VERIFIED]` 为公开页面直接核实；`[DOCUMENTED]` 为官方资料明示；`[PRIMARY]` 为创作者本人公开说明；`[INFERRED]` 为待盲测的听感/工程推断；`[UNKNOWN]` 为当前资料未确认。

## 结论先行

1. **目标声音首先是“选对系统音色”，不是复杂调参或克隆。** `[PRIMARY]` 参考视频评论区有人询问为什么自己的 `Speech-2.6-Turbo` 很生硬，作者回答自己基本使用默认参数，并建议“换个音色试试”。另两处作者回复把参考音色指向 API 侧的 `Podcast_girl`，并说明网页端可能没有。这个线索比猜测后期插件更有价值。
2. **最低成本的第一轮应直接测 MiniMax `speech-2.8-hd` 与 `speech-2.8-turbo`，不做真人克隆。** `[DOCUMENTED]` 直连 MiniMax 与阿里百炼代理公开价相同：Turbo 2 元/万计费字符，HD 3.5 元/万计费字符；中文汉字按 2 个字符计费。当前统一基准一次为 374 个计费字符，单次约 **0.0748 元 Turbo / 0.1309 元 HD**。
3. **`Podcast_girl` 不能写死为永久可用。** `[VERIFIED]` 它没有出现在本次查看的静态官方系统音色清单中，但官方提供 `get_voice` 查询账号当前可用音色。正式接入时必须先查询；查不到就测官方现有的温暖/柔和女声，再用 Voice Design 生成原创声线。
4. **MiniMax 现在已经满足当前流水线的关键工程合同。** `[DOCUMENTED]` 同步 HTTP 可返回句级、词级或流式词级时间戳；支持固定停顿、拼音/IPA 发音修补、40 种语言、速度/音量/音高、情绪和 Speech 2.8 专属语气词。它不再需要用“按字数均分字幕”降级。
5. **合法免费层只适合内部试听，不应当作发布生产线。** MiniMax 语音网页产品提供每日限时免费声贝，但下载带水印，用户协议还要求披露 AI 使用；MiniMax 开放平台按量 API 没有公开承诺的免费 TTS 字符额度，阿里百炼 MiniMax 路线明确写“无免费额度”。“免费用户 10 RPM”只是限速等级，不是赠送字符。
6. **若 `Podcast_girl + Speech 2.8 HD` 仍达不到目标，再进入原创 Voice Design，而不是克隆 UP。** 音色设计激活一次 9.9 元，试听文本按 Turbo 价计费；用抽象描述生成与真人无映射的账号女声，成本仍很低且权利链更清楚。

## 参考声音：可迁移的抽象特征

以下不是目标声纹规格，也不是对某个自然人的身份识别；它是用于统一盲测的导演卡。由于本轮按边界没有下载、分离或转录原视频，听感项按 `[INFERRED]` 处理，最终以同稿、同响度盲听为准。

| 维度 | 可迁移目标 | 应避免 |
|---|---|---|
| 声线 | 年轻成年女声；中高音区但不尖；干净、轻盈、亲近；气声只作质感，不吞字 | 萌妹夹声、客服微笑、新闻播音腔、刻意模仿作者 |
| 节奏 | 中速偏快；信息句紧凑，解释句稍松；语速跟信息密度变化，不全段恒速 | 每个标点停同样时长、赶稿式连读、整段拉伸修速度 |
| 停连 | 短语内部连贯；主题切换与关键词前有 150–350 ms 微停；段落切换 400–700 ms | 每句都用长停顿、句尾机械补空白 |
| 重音 | 每句只突出 1–2 个信息词；重音来自轻微能量和时值变化，不靠突然升调 | 句句“播报式”强调、所有专名都重读 |
| 情绪弧 | 主体是克制、好奇、清醒；开头略亮，中段随信息起伏，结尾自然回落 | 全程高兴、夸张表演、每句相同上扬尾音 |
| 咬字 | 普通话清楚但不逐字雕刻；数字、缩写、专名单独校音；齿音不刺 | 为清晰度牺牲连贯性、拼音腔英文 |
| 中英混读 | 英文词组按英文韵律成组，前后中文声线连续；数字和缩写用文本规范化/词典校正 | 把英文逐字母化、中文突然切成另一位说话者 |
| 后期 | 先统一响度再盲测；最多轻度去齿、窄幅 EQ、温和压缩与峰值保护 | 重度降噪、混响、变调或激励器掩盖模型问题 |

### 为什么“音色优先”比“参数优先”更可信

- `[PRIMARY]` 作者对 `Speech-2.6-Turbo` 生硬问题的回复是默认参数、换音色，不是提供一组隐藏参数。
- `[PRIMARY]` 作者两次公开回复均指向 `Podcast_girl`，其中一次明确说“好像只有 API 才有”。
- `[INFERRED]` 因此，参考效果很可能主要来自 **系统音色资产 + 模型上下文韵律 + 合理脚本标点/分段**，后期只是完成度，不是根因。
- `[UNKNOWN]` 作者没有在该页公开完整请求 JSON、模型快照、后期链或响度参数，不能把任何猜测写成事实。

## MiniMax Speech 2.8 能力核验

### 模型与合成能力

| 项目 | 官方现状 | 对本项目的价值 |
|---|---|---|
| `speech-2.8-hd` | 情绪渲染与语气词，官方播客方案称其自然度最高 | 最终质量候选、英雄句与成片 A/B |
| `speech-2.8-turbo` | 更快、更便宜，也支持 Speech 2.8 语气词 | 批量草稿、普通段落与成本基线 |
| 语言 | 40 种语言，含中文、粤语、英文；`language_boost=auto` 或指定语言 | 中文、英文整句和中英混读可走同一供应商 |
| 停顿 | 文本内 `<#x#>`，范围 0.01–99.99 秒 | 直接实现语义停顿，不用后期切静音 |
| 语气词 | Speech 2.8 支持笑、轻笑、呼吸、吸气、呼气、叹气、`emm` 等标签 | 少量加入人类气口；禁止每段堆标签 |
| 发音 | 支持拼音、IPA、粤拼行内覆盖；另有发音词典 | 修复专名、多音字和英文，不重生成整段 |
| 声音控制 | 速度、音量、音高、情绪；还可做 timbre mix/声音效果器 | 先保持默认，只在失败样本上单变量调节 |
| 同步长度 | 单次小于 10,000 字符，超过 3,000 建议流式 | 8–20 秒语义块完全足够 |
| 异步长文 | 最长可到大体量长文本，官方接口概览写单次最高 100 万字符 | 有声书/长故事后备，不用于首轮短视频 A/B |

### 时间戳与字幕

- `[DOCUMENTED]` 同步 HTTP 设置 `subtitle_enable=true` 后可选择：
  - `sentence`：句级时间戳；
  - `word`：词级时间戳；
  - `word_streaming`：流式优化词级时间戳，仅流式请求。
- `[DOCUMENTED]` 异步长文本官方概览只承诺句级字幕，因此当前短视频应优先同步 HTTP 的 `word`。
- `[DOCUMENTED]` 非流式音频 URL 有效期 24 小时；异步结果 URL 时效更短。生产适配器必须立即落盘、校验实际时长并保存 manifest，不能把临时 URL 当资产。
- `[INFERRED]` 中文“词”边界仍需抽查；如果 API 返回边界无法直接映射逐字字幕，保留原始词时间并做确定性细分，不伪称原生逐字时间。

### 系统音色、Voice Design 与 Voice Cloning

| 路线 | 输入 | 费用 | 权利与用途 |
|---|---|---:|---|
| 系统音色 | 官方 `voice_id` | 只有合成字符费 | **首选**；没有参考音权利风险 |
| Voice Design | 抽象声音描述 + 试听文本 | 首次正式合成激活 9.9 元/音色；试听按 2 元/万字符 | **原创账号声线首选**；不写真人姓名或“像某某” |
| Voice Cloning | 10 秒–5 分钟有权利的参考音；可加小于 8 秒示例 | 首次正式合成激活 9.9 元/音色；试听按所选模型计费 | 只用本人、签约配音员或书面授权素材 |

- 设计/复刻音色生成后是临时音色；MiniMax 官方说明需在 168 小时内正式调用一次以保留。
- 快速复刻需要个人或企业认证。接口无状态说明不等于可以上传无授权声音。
- `get_voice` 可查询账号当前系统、复刻和设计音色。`Podcast_girl` 若查询不到，不通过抓包、旧账号或第三方共享 Key 绕过。

## 建议的 MiniMax 正式 A/B（未调用）

### 第 0 步：只查询，不生成

1. 用户自行完成 MiniMax 开放平台账号、认证、充值/预算上限和 API Key 配置；Key 只放本机环境变量。
2. 调用官方 `get_voice`，查找 `Podcast_girl` 的真实当前 ID 与可用范围。
3. 若不存在，固定四个官方当前女声候选：`Chinese (Mandarin)_Warm_Bestie`、`Chinese (Mandarin)_Gentle_Senior`、`Chinese (Mandarin)_Soft_Girl`、`Chinese (Mandarin)_Warm_Girl`；不要猜旧 ID。

### 第 1 步：默认参数复现作者线索

统一文本：`90_模板库/T10_语音盲测基准.txt`。

```json
{
  "model": "speech-2.8-hd",
  "voice_setting": {
    "voice_id": "<get_voice 实际返回值>",
    "speed": 1,
    "vol": 1,
    "pitch": 0
  },
  "language_boost": "auto",
  "subtitle_enable": true,
  "subtitle_type": "word",
  "audio_setting": {
    "sample_rate": 32000,
    "format": "wav",
    "channel": 1
  }
}
```

- 第一轮不传显式 `emotion`，不插入呼吸标签，不做声音效果器；先验证“音色 + 新模型 + 默认参数”。
- HD/Turbo 各 3 次；保存模型、voice ID、参数、计费字符、音频实际时长、字幕原始响应、文件哈希和 trace ID。
- 试听前仅做无损裁切与同响度归一，统一约 -16 LUFS、true peak 不高于 -1 dB；评委不知道供应商、模型和音色。

### 第 2 步：单变量导演

只有默认参数样本通过自然度门后，才依次单独测试：

1. 标点与 150–350 ms 语义停顿；
2. `calm` 与不传 emotion；
3. 中英混读的 `language_boost=auto` 与分块英文；
4. 仅在真实换气位置加 1–2 个 `(breath)`；
5. 数字开启文本规范化，专名用拼音/IPA 修补。

禁止一次同时改速度、音高、情绪、停顿和后期，否则无法知道为什么变好。

### 第 3 步：原创 Voice Design（仅在系统音色未达标时）

不提真人或参考 UP，使用以下抽象方向设计 3 个音色、每个 2 个候选：

> 年轻成年中文女声，中高音区但不尖，清醒、亲近、略带播客感；中文自然，英文词组不切换声线；信息句紧凑，解释句略松；关键词轻重音清楚，句尾自然回落。禁止客服腔、新闻腔、卖萌、夸张气声和整段等速。

入围后支付一次 9.9 元激活，并把设计 prompt、voice ID、日期、条款快照和 `real_person_reference=false` 写入声音资产 manifest。

## 最终决策

在“最快接近参考质量”这个目标上，首个云候选应是：

1. `Podcast_girl`（若 `get_voice` 仍返回）+ `speech-2.8-hd` 默认参数；
2. 同音色 + `speech-2.8-turbo` 成本对照；
3. 四个当前官方温暖/柔和女声；
4. MiniMax Voice Design 原创女声；
5. 再与本地 Qwen3-TTS 1.7B、VoxCPM2、CosyVoice3 的同稿原始 WAV 盲测。

这条顺序把云端“演员感”基准的直接成本压到 1 元以内，并且不引入真人声纹权利风险。未试听前不宣称任何本地模型、MiniMax 新模型或 `Podcast_girl` 已经达到参考成片；用同稿盲测结果决定默认引擎，而不是凭品牌或参数大小决定。
