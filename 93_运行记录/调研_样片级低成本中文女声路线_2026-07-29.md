# 调研：样片级低成本中文女声路线（2026-07-29）

- 目标：以最低合法总成本接近参考 UP 的中文女声完成度；不识别、复刻或训练其声纹。
- 参考样片：[《轻松复刻！爆肝揭秘万粉 UP 主是如何炼成的，我的 AI 早报“生产线”大公开。》](https://www.bilibili.com/video/BV1B82DBdEdP/)
- 本机：Windows 11、RTX 3060 Ti 8GB、约 64GB 内存。
- 证据：产品能力、价格、免费额度、显存和许可只采用官方文档、官方仓库、官方模型卡；价格与产品状态核验日为 2026-07-29。
- 操作边界：本轮只读获取样片音轨并在系统临时目录做声学/ASR 检查；没有把样片或切片写入仓库，没有克隆声音、调用付费 API、创建账号、安装环境或下载 TTS 权重。
- 标签：`[VERIFIED]` 本机或页面实测；`[DOCUMENTED]` 官方明示；`[PRIMARY]` 作者本人公开说明；`[INFERRED]` 工程推断；`[UNKNOWN]` 尚未实听/实测。

## 结论先行

1. **最低成本的正确答案不是“只跑本地”，而是先花不到 1 元找出云端质量上限，再决定是否承担本地工程成本。** 当前 T10 基准为 374 个 MiniMax 计费字符；单次 MiniMax HD 约 `0.1309 元`，而 Qwen3-TTS-Instruct-Flash 或 CosyVoice 3.5 Flash 约 `0.0299 元`。省下几分钱却增加数分钟修音，不是更低成本。
2. **最接近参考样片的第一候选仍是 MiniMax `speech-2.8-hd + Podcast_girl`，但必须先查询账号音色清单。** `[PRIMARY]` 作者在该视频公开评论中称基本使用默认参数，并把音色线索指向 API 侧 `Podcast_girl`；该 ID 不在静态官方清单，不能写死为永久可用，也不能据此克隆作者。
3. **2026-07 新上线的更强/更便宜挑战者必须加入第一轮。** `[DOCUMENTED]` `qwen-audio-3.0-tts-plus` 主打高质量、细粒度标签和 free-style 指令，`1.4 元/万字符`；`cosyvoice-v3.5-plus` 主打超高表现力、跨语种与自由指令，`1.5 元/万字符`；其 Flash 为 `0.8 元/万字符`。它们比 MiniMax HD 便宜，但“官方描述更强”不等于本项目听感已胜出。
4. **本地首测顺序改为 Qwen3-TTS 1.7B → VoxCPM2 → CosyVoice3。** Qwen 1.7B 最容易用 Serena/Vivian 建立强基线；VoxCPM2 的原创 Voice Design/情绪上限更高但官方约 8GB VRAM，正卡本机极限；CosyVoice3 0.5B 适合 WSL2 与合法参考声路线。
5. **“别人开源项目”只作为部署壳，不会自动提高声音质量。** 首轮用模型官方仓库建立可复现基线；ComfyUI、WebUI、整合包、第三方量化和镜像必须分别审计代码、权重与许可证，不能把第三方项目的 README 当上游授权。
6. **合法免费额度可以用，但不做换号、共享 Key、身份轮换或绕限流。** 腾讯云通用 TTS 官方提供一次性 800 万字符、3 个月；百度个人认证的大模型声音复刻提供 10 次创建与 5 万合成字符；阿里百炼只使用控制台实际显示的模型额度并打开“用完即停”。这些路线是免费对照，不先验等于样片级质量。
7. **参考完成度不仅来自音色。** 样片混合音轨显示约 4.6–5.2 个中文字符/秒、停顿中位数约 420ms、P90 约 650ms、LRA 3.5 LU；这是“快而不赶、连续但有语义停顿”的导演与剪辑结果。只换模型、仍按标点机械切句，AI 味不会消失。

## 一、参考样片的可验证目标

### 1.1 页面与音轨

- `[VERIFIED]` 页面标题、作者和视频长度可见；音轨实际时长 `504.849s`，AAC、44.1kHz、双声道、约 `76.4kbps`。
- `[VERIFIED]` 对 5s、150s、330s 起的三个 25 秒片段，以仓库已有 faster-whisper-small 在 CPU 做只读 ASR：中文识别速度分别约 `4.60 / 5.08 / 5.16` 个汉字/秒。ASR 有少量同音字错误，但连续技术名词和长句总体可懂。
- `[VERIFIED]` 全片混合音轨 EBU R128：Integrated `-21.1 LUFS`、LRA `3.5 LU`、True Peak `-5.4 dBFS`。
- `[VERIFIED]` 以 `-35dB / 200ms` 阈值近似检测到 237 个停顿：总计 102.11s，中位数 `420ms`、P90 `650ms`、最大 `810ms`；83 个不超过 350ms，149 个在 350–700ms，只有 5 个超过 700ms。

限制：当前模型不支持直接听取工具返回的音频，因此本文不假装给出耳朵主观结论；主观“好听”采用用户评价，音色线索采用作者公开说明，本文补充可重复的声学指标。停顿统计来自混合音轨并受 BGM/门限影响，只用于节奏近似，不能当逐字真值。

### 1.2 可迁移导演卡

| 维度 | 可执行目标 | 失败模式 |
|---|---|---|
| 声线 | 年轻成年女声，中高音区但不尖，清晰、轻盈、亲近，低气声 | 夹声、客服笑、新闻腔、刻意模仿作者 |

## 三、推荐生产栈

### 立即采用的“云锚 + 本地挑战者”

1. **质量锚**：MiniMax Speech 2.8 HD；账号返回 `Podcast_girl` 时首测它，否则测 2 个官方温暖/柔和女声。参数第一轮保持默认，只做合理分段。
2. **更强低价挑战者**：Qwen-Audio 3.0 TTS Plus 选 2 个女声；CosyVoice 3.5 Plus 设计 2 个原创女声；另以 CosyVoice 3.5 Flash 检查质量损失是否可接受。
3. **无设计成本系统音色对照**：Qwen3-TTS-Instruct-Flash 选 2 个女声，统一导演指令。
4. **本地挑战者**：关闭 GPU 占用后先跑 Qwen3-TTS 1.7B Serena/Vivian；通过显存与稳定性后再跑 VoxCPM2 Voice Design。
5. **生产路由**：普通段落使用通过门槛的最低价 Flash/本地候选；英雄句、强情绪段只有在盲测显著胜出时才用 Plus/HD。不要在同一角色中混用听得出不同声纹的模型。

### 导演与后期合同

- 文本按语义 beat 切分，不是见逗号就请求；每段尽量 2–4 句，让模型看到上下文。
- 目标信息段 4.8–5.2 汉字/秒；常规停顿 0.35–0.65s，章节停顿 0.7–1.0s。
- 第一轮 `speed=1 / pitch=0 / emotion=auto`；只有基线确定后一次只改一个变量。
- 先无 BGM 盲测模型，再统一混同一 BGM；响度匹配参考样片约 `-21 LUFS` 只用于公平对照，不把它直接定为全平台发布标准。
- 许可、真实时长、时间戳、成本、模型快照、音色来源和 seed 必须写 manifest。

## 四、A/B 盲测：两天内得出答案

### 漏斗 A：不超过 1 元的云端决赛

- 文本：T10 的 A/B/C 三段；先每候选 1 seed。
- 候选：MiniMax HD 2 音色、Qwen-Audio Plus 2 音色、Qwen3 Instruct 2 音色、CosyVoice 3.5 Plus/Flash 同一原创音色。
- 统一：24k/32k WAV、mono、无后期、同响度；随机改名 `S01...S08`，不显示厂商。
- 评分：自然度、节奏/停顿、重音、情绪弧、咬字/专名、英文、中英换人感、60 秒耐听，各 1–5。
- 硬门：自然度/咬字/英文均值 ≥4.0；无关键错读；不能有规律句尾、均匀气声、漏字、重复、金属尾音。
- 只有用户 1 人时：上午/晚上两次换序复评；Top 3 再各 3 seed，避免一次幸运样本。

### 漏斗 B：本地是否值得

- 只让 Qwen Serena/Vivian、Qwen VoiceDesign、VoxCPM2 与云端 Top 2 比，不拿 Edge 当最终上限。
- 记录峰值显存、RTF、冷启动、失败率、100 段连续稳定性、时间戳误差和每分钟人工修音时间。
- 本地只有在听感不退化且单条人工返工不高于云端时，才替换默认；否则保留为隐私/离线回退。

### 样片相似度不是声纹相似度

最终目标向量为：`4.8–5.2字/秒 + 0.35–0.65s语义停顿 + 克制低动态 + 每句1–2个信息重音 + 干净年轻女声 + 正确中英混读`。不得把“像该 UP”转化成声纹相似度评分，也不得用其音轨作克隆 prompt。

## 五、下一步可直接执行

### 5.1 先查 MiniMax 音色，不产生 TTS 费用

账号、实名、充值与 Key 由用户在官方平台完成；Key 只放当前进程环境变量：

```powershell
$env:MINIMAX_API_KEY = "在本机粘贴，不写入仓库"
python .\92_工具箱\tts_minimax.py voices `
  --voice-type system `
  --out .\.tools\minimax_contract\voices_2026-07-29.json `
  --execute --confirm-billable
```

若返回清单确实包含 `Podcast_girl`，先跑 T10 HD；否则把 `--voice-id` 换成清单内候选：

```powershell
python .\92_工具箱\tts_minimax.py synthesize `
  --text-file .\90_模板库\T10_语音盲测基准.txt `
  --out .\.tools\voice_ab\minimax_hd_podcast_girl `
  --model speech-2.8-hd `
  --voice-id Podcast_girl `
  --voice-source system `
  --max-cost-cny 0.50 `
  --execute --confirm-billable
```

该命令只生成影子候选，不覆盖现有旁白。首次真实响应后先检查 raw 字幕字段，再补 `words[]` 解析，未完成前不得宣称逐词合同已落地。

## 六、最终决策门

- 若 MiniMax HD `Podcast_girl` 在盲测明显第一：直接按量生产。60 秒约两角，通常比本地返修便宜。
