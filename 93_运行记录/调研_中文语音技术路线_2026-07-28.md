## 结论先行

1. **不要立刻替换当前生产链。** 保留 `edge-tts` 作为已跑通的质量/时长/字幕基线，但由于它是第三方客户端调用 Edge 在线朗读服务、无需官方 API Key，未找到微软对这种批量商用调用的明确授权，故只作为内部试制与故障回退，不把“能免费调用”解释为“可稳定商用”。[edge-tts 官方仓库](https://github.com/rany2/edge-tts)
2. **本地首测 Qwen3-TTS 0.6B。** `[DOCUMENTED]` 代码与模型为 Apache-2.0，0.6B Base 支持 3 秒声音克隆，0.6B CustomVoice 有 9 个内置音色；1.7B 才覆盖更完整的自然语言控制/声音设计。官方未给最低显存，故“0.6B 可在 8GB 上运行”只能列为 `[INFERRED]`，必须实测后决定。[官方仓库](https://github.com/QwenLM/Qwen3-TTS) · [0.6B Base 模型卡](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base)
3. **本地第二优先 VoxCPM2，但它正好踩显存边界。** `[DOCUMENTED]` 权重与代码 Apache-2.0、官方明确“免费商用”，支持中文、方言、音色设计、可控克隆、情绪/语速指令和可选词级时间戳；官方标注约 8GB 显存，等于本机物理上限，容易因 CUDA/ASR/桌面占用 OOM。应串行加载并先关闭 denoiser；失败就退到约 6GB 的 VoxCPM1.5，而不是强行超售显存。[官方中文 README](https://github.com/OpenBMB/VoxCPM/blob/main/README_zh.md)
4. **云端首选阿里百炼作为正式低价后备。** `[DOCUMENTED]` Qwen3-TTS Flash/Instruct/VC/VD 均为 0.8 元/万字符并各有 1 万字符/90 天试用；CosyVoice v3.5 Flash 同为 0.8 元/万字符并有 1 万字符/90 天试用。CosyVoice HTTP 可返回词/字级起止时间，能直接接当前字幕合同。[官方模型价格](https://help.aliyun.com/zh/model-studio/model-pricing) · [CosyVoice HTTP 返回结构](https://help.aliyun.com/en/model-studio/cosyvoice-tts-http-api)
5. **“情绪强”不等于“可生产”。** IndexTTS2 的音色/情绪解耦很强，但仓库说明的精确时长控制在公开版本中尚未启用，且 README 要求商用联系团队、模型使用协议又给出带门槛的授权，存在解释风险；Fish Speech 本地权重明确要求商业用途另签许可证；ChatTTS 与 F5-TTS 官方权重均非商用。前三者只能按本文边界处理。
6. **声音矩阵应蒸馏“表达参数”，不能蒸馏“真人身份”。** 可以从公开视频抽象节奏、停顿、情绪弧、句长、强弱重音、视角和叙事结构；不得下载并克隆未授权主播、演员、名人或普通人的音色。账号矩阵优先使用原创声音设计、平台明确授权音色或本人/签约配音员书面同意的参考音。

| 优先级 | 方案 | 当前定位 | 升级判断 |
|---|---|---|---|
| P0 | `edge-tts` | 已验证基线/临时回退 | 保留，但不作为长期商用依赖；不要并发薅取或规避限制 |
| P1 | Qwen3-TTS 0.6B Base + CustomVoice | 首个本地 PoC | 8GB 实测通过、中文盲评胜出且 100 段稳定后，升级为本地默认 |
| P1 | 阿里百炼 Qwen3-TTS Instruct/VC 或 CosyVoice v3.5 Flash | 正式云后备 | 原生词级时间戳、低价、可设“免费额度用完即停”；适合立即接适配器 |
| P2 | VoxCPM2 | 情绪/音色设计/克隆高价值 PoC | 约 8GB 边界；若 OOM 或 RTF 过高，暂不生产部署 |
| P2 | CosyVoice 3 0.5B 本地 | 方言与自然语言控制候选 | Windows/显存由本机验证后再提升；云版可先替代验证能力 |
| P2 | GPT-SoVITS v4 | 长期角色音色工坊 | 适合已授权、长期复用角色；不是当前“一键批量旁白”首选 |

| 兜底 | MeloTTS / EmotiVoice | 离线固定音色/低算力 | 质量盲评达标才作为无网降级，不承担高保真克隆 |

## 字幕与时间轴的统一策略

当前链最有价值的不是某个音色，而是“音频实际时长 + 逐词/逐字时间 + 可复现 manifest”。替换 TTS 时不得丢掉这层合同。

统一输出建议：

```json
{
  "provider": "local:qwen3-tts",
  "model": "Qwen3-TTS-12Hz-0.6B-CustomVoice",
  "model_revision": "pinned-commit-or-snapshot",
  "voice_id": "original-designed-voice-id",
  "consent_record": null,
  "text_sha256": "...",
  "audio_path": "...",
  "duration_sec": 0.0,
  "sample_rate": 24000,
  "timestamps_source": "provider|stable-ts|faster-whisper",
  "words": [
    {"text": "示例", "start": 0.0, "end": 0.4, "confidence": null}
  ],
  "generation": {
    "seed": 42,
    "instruction": "克制、低声、叙事感",
    "reference_audio_sha256": null
  },
  "license_checked_at": "2026-07-28",
  "cost": {"currency": "CNY", "amount": 0.0, "billable_units": 0}

```

时间戳优先级：

1. 供应商/模型原生词级时间戳（阿里 CosyVoice、腾讯支持音色、Fish timestamp API、Azure WordBoundary）。
2. 本地 VoxCPM 的 stable-ts 后对齐；明确标记为 `best-effort`。
3. 其他本地模型先生成 WAV，再用当前 `faster-whisper` 词级时间对齐；不根据字数平均摊时间。
4. 对数字、英文、专名和情绪性拖音做人工抽查；生成文案、实际朗读文本、字幕文本三者 hash/内容必须可追溯。

## 分阶段评测计划

### 阶段 0：固定基线，不花钱

- 冻结当前 72.27 秒旁白为 `edge-tts` 基线，不重新生成覆盖。
- 从现有故事稿抽 3 组测试，每组 45–75 秒：
  - A：克制、温暖、缓慢的叙事；
  - B：悬疑、压迫、由平静到紧张的情绪弧；
  - C：数字、年份、人名、中英混读、问句、长句与多音字压力测试。
- 每个方案使用完全相同的规范化文本；保留 WAV、参数、seed、真实时长、日志和模型 revision。

### 阶段 1：本地 8GB 可行性（零账号、零 API）

1. **Qwen3-TTS 0.6B CustomVoice**：先测内置音色，避开声音权利变量。
2. **Qwen3-TTS 0.6B Base**：只用本人录音或项目自行录制且有明确授权的干净参考音；不使用博主/演员片段。
3. **VoxCPM2**：单模型串行、`load_denoiser=False`，记录冷启动、峰值显存、RTF；一旦 OOM，转测 VoxCPM1.5，不做系统级 swap/强占显存的“成功”。
4. **CosyVoice3 0.5B**：独立虚拟环境；原生 Windows失败时可测 WSL2，但分别记录部署难度，不把 WSL2 成功写成 Windows 原生成功。

每个模型至少运行：3 个风格片段 × 3 个 seed + 连续 100 个短段稳定性测试。通过门槛：

- 内容：数字/专名无关键错读；ASR CER 仅作筛查，最终以人工逐句核对为准。
- 字幕：抽 20 个词/字人工打点，median 偏差 ≤120ms、p95 ≤250ms；超出则不得沿用现有字幕动画节奏。
- 听感：3 人盲评（或同一人分时复评），自然度、情绪贴合、角色一致性、可懂度各 1–5；自然度与可懂度均值至少 4.0。
- 性能：单段无 OOM，连续 100 段无显存持续增长或崩溃；记录 peak VRAM、RTF、首包/总耗时。
- 可复现：同 seed 结果可重复或至少参数齐全；失败可自动回退而不覆盖已通过音频。

### 阶段 2：低价云 A/B

- 启用阿里百炼“免费额度用完即停”，只调用固定的模型快照：
  - `qwen3-tts-instruct-flash-2026-01-26`；
  - `qwen3-tts-vc-2026-01-22`（仅授权参考音）；
  - `cosyvoice-v3.5-flash`。
- 腾讯只领取官方控制台显示的合法免费包；先核对音色实际适用额度、时间戳和商用协议，不以“800 万字符”作为提前批量生成的理由。
- Fish `s2.1-pro-free` 仅做开发盲评；免费条款冲突未解决前，生成物不进入发布目录。
- 每次请求设置单次与当日预算上限；错误重试指数退避并设置最大次数，不轮换账号或密钥绕限流。

### 阶段 3：生产影子运行

- 默认引擎仍产出正式候选，新引擎只产出同稿影子版；G3 人工选择，不自动替换。
- 连续 10 条内容记录：返工次数、错读数、人工修音分钟、平均成本、失败率、字幕偏差和听感分。
- 只有当新引擎在质量、稳定性、许可、时间戳和总成本五项均不退化时，才更新默认路由。

## 账号矩阵的声音资产方法

建议每个账号维护“声音卡”，而不是保存一段来路不明的博主录音：

- `voice_asset_id`：项目内稳定 ID；
- 来源：`platform_builtin` / `voice_design` / `self_recorded` / `contracted_actor`；
- 模型与快照、设计 Prompt、seed；
- 允许的平台、地域、期限、商业用途；
- 参考声音授权人、授权日期、证据位置；
- 禁止项：真人姓名/艺名、暗示官方背书、未授权相似音色；
- 复测记录：自然度、情绪、错读、模型漂移；
- 撤回机制：权利人撤回或条款变化时，能定位并停用全部派生音频。

可学习并参数化的“风格蒸馏”字段：

- 每分钟字数、句长分布、停顿密度、前 3 秒能量；
- 情绪弧（平静→疑问→紧张→释放），而不是“像某某说话”；
- 重音位置、气声/低语使用频率、句尾走向；
- 单人叙述/角色对话比例、旁白与对白音色距离；
- 账号固定的语速、响度、动态范围与字幕节奏。

## 安全与合规硬约束

- **禁止未经同意克隆真人声音。** 包括公开视频中的 UP 主、主播、演员、名人、朋友、客户和普通用户；“公开可听”不等于“允许训练、克隆或商用”。
- 仅接受本人声音、签约配音员、具备可验证授权的声音，或明确允许商业使用的系统/原创设计音色。
- 不使用换号、脚本注册、验证码平台、代理池、共享密钥或拆分请求规避免费额度、并发、地域和计费限制。
- API Key 仅放本机环境变量/密钥存储，不写入仓库、日志、字幕 manifest 或媒体元数据。
- 上传云端前最小化数据；参考音需获得“上传第三方云处理”的单独授权。敏感项目默认本地。
- 所有发布成片延续项目的 `AI生成内容` 可见标识和平台声明；不得用合成声音制造真人背书、新闻采访或事实证言。
- 供应商条款、模型权重或音色授权变化时，停止新生成；已有素材是否可继续用要按取得时条款与保存的证据单独判断。
