# GitHub 声音训练与变声路线审计

- 调研日期：2026-07-29
- 本机：RTX 3060 Ti 8GB；调研时空闲显存约 5.7GB，D 盘约 122.7GB
- 目标：以最低成本达到自然、情绪稳定、角色感强的中文女声；生产默认使用原创相邻声线或授权数据
- 非目标：抓取 UP、声优或游戏角色音频进行未授权克隆

## 一、结论

1. **参考作品那种“像原角色”的声音，技术上可以通过 TTS 克隆或 `表演底片 → VC` 达成；权利上不能把“能做到”直接变成生产方案。** 未经授权的角色/声优音色只做技术分析，不进入可变现成片。
2. **本项目性价比第一名不是训练，而是 MiniMax Voice Design + Speech 2.8 HD。** 官方价为音色首次启用 9.9 元、HD 3.5 元/万字符；当前 374 计费字符基准约 0.1309 元/次，最适合先建立一个不指向真人的原创女声锚点。[官方按量计费](https://platform.minimaxi.com/docs/guides/pricing-paygo)
3. **本地第一梯队是 Qwen3-TTS 1.7B VoiceDesign/CustomVoice 与 VoxCPM2。** 两者代码/官方权重均为 Apache-2.0；VoxCPM2 官方给出的推理显存约 8GB，正好卡在本机边界，必须清空其他 GPU 占用后小样验证，不能承诺稳定批量生产。[Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)；[VoxCPM2](https://github.com/OpenBMB/VoxCPM)
4. **如果未来取得合法角色声音授权，`人工表演 → RVC/Seed-VC` 往往比纯 TTS 更接近动画角色。** 原因是停顿、笑声、气息、重音和情绪弧由人先演出来，VC 只负责音色迁移。
5. **F5-TTS 官方基础权重和 Fish Speech 当前本地权重不适合本项目的变现生产。** F5 官方基础权重为 CC BY-NC 4.0；Fish 2026 研究许可要求商业使用另签协议。[F5 模型卡](https://github.com/SWivid/F5-TTS/blob/main/src/f5_tts/infer/SHARED.md)；[Fish 许可](https://github.com/fishaudio/fish-speech/blob/main/LICENSE)

## 二、先分清三类任务

| 类型 | 输入 | 强项 | 弱项 | 本项目用途 |
|---|---|---|---|---|
| TTS | 文本 + 音色/指令 | 批量、可改稿、易接字幕 | 情绪容易平均化 | 旁白、常规对白 |
| Voice Conversion | 已演好的语音 + 目标音色 | 保留表演、笑声、气息与节奏 | 需要底片演员；音色授权风险高 | 高情绪角色对白 |
| Fine-tune/LoRA | 授权数据 + 基座 | 稳定专属声线 | 数据清洗、训练、维护成本 | 长期原创声音资产 |

达到参考级的关键通常不是“模型名”，而是：`文本导演 → 表演/韵律底片 → 音色渲染 → 逐句挑选 → 去噪响度 → 强制对齐 → 口型/字幕`。

## 四、三档可执行方案

### A 档：参考级但必须有授权

`人工/配音演员表演底片 → RVC 或 Seed-VC → 人工逐句挑选 → EQ/降噪/响度 → 强制对齐`

- 适合：强情绪、笑哭、低语、打断、多人角色剧。
- 前提：底片表演者同意；目标音色为自有/授权声音；训练数据来源、同意书、用途和期限可追溯。
- 成本：模型成本低，主要成本是表演、数据清洗、逐句返工和口型修正。
- 结论：**技术上最接近游戏角色演出，权利风险也最高。** 目前不进入生产。

### B 档：本项目首推性价比

`MiniMax Voice Design 生成 4–6 个原创相邻女声 → 激活 1 个 → Speech 2.8 HD 同稿三段盲测 → 强制对齐`

- 音色描述只写年龄段、明暗度、气息、能量、共鸣位置、语速和情绪范围；不得写声优/角色名。
- 官方 Voice Design 首次启用 9.9 元，试听按 TTS 字符计费；HD 为 3.5 元/万字符。[官方价格](https://platform.minimaxi.com/docs/guides/pricing-paygo)
- 可用官方合法优惠，不换号、轮换身份或绕限流。MiniMax 当前订阅方案列有 Speech 2.8 日额度，但调用前需确认该 Key/套餐是否覆盖目标接口。[Token Plan](https://platform.minimaxi.com/docs/guides/pricing-token-plan)
- 结论：**最可能以十元级一次性成本达到可发布的自然女声**，且无需先维护本地模型。

### C 档：零 API 成本、本地长期资产

`Qwen3-TTS VoiceDesign → 固化声音指纹/提示词 → CustomVoice 或 VoxCPM2 渲染 → 本地后处理`

- 第一步先跑 15–20 秒样片，不下载多个模型同时试。
- 本机 RTX 3060 Ti 8GB 必须先释放大部分显存；调研时只有约 5.7GB 空闲，不满足边界模型的安全余量。
- VoxCPM2 官方标注约 8GB VRAM，且 5–10 分钟音频可 LoRA；这意味着“能启动”不等于“能在同时开浏览器/剪辑软件时稳定生产”。[官方仓库](https://github.com/OpenBMB/VoxCPM)
- 结论：单条边际成本最低，但初次环境、模型下载、速度、显存和维护的隐性成本最高。

## 五、为什么当前不建议直接训练“鸣潮角色声线”

1. 声优/角色声音可识别性强，训练数据通常来自游戏、直播或公开视频；“公开可听”不等于“允许抽取训练”。
2. 国内深度合成规则对合成人声、仿声和生物识别信息编辑有专门要求，涉及个人声音时需依法告知并取得单独同意。[官方规定](https://www.cac.gov.cn/2022-12/11/c_1672221949354811.htm)
3. 角色 IP、声优人格权、录音制品权、游戏条款和平台规则是不同权利层；只获得其中一层不代表整条链闭环。
4. 即使技术 A/B 只在本地，最终进入变现账号仍需单独生产许可判断。

## 六、自然度的生产控制

同一个模型从“AI 味”到“角色演出”的差距主要来自以下控制：

1. 每句只承载一个动作或情绪目标，长句先改稿，不靠模型硬读。
2. 标注 `意图 / 对象 / 潜台词 / 能量 / 速度 / 句尾 / 呼吸点`，不用“更自然一点”这种空指令。
3. 对强情绪句生成 3 个候选，只换一个变量；连续两次无改善就改文案或换路线。
4. 中文自然度和英文混读分开打分；角色短剧可按语言分段，但需检查音色和空间感是否跳变。
5. 任何云/本地 TTS 若无可靠词时间戳，发布字幕与口型统一走强制对齐，不猜供应商字段。
6. 保存模型 revision、音色 ID、prompt、seed（若有）、输入文本、成本、音频哈希和授权记录。

## 七、下一步实验门

不触碰账号、付费或大模型下载的情况下，本轮只能完成方案与执行器审计。下一次最小实验二选一：

- **云端推荐：** 用户配置 MiniMax Key 并授权约 10.5 元总上限，创建原创女声并跑 T10 三段；不克隆任何真人/角色。
- **本地推荐：** 用户释放 GPU 并授权下载一个模型，只选 Qwen3-TTS 1.7B 或 VoxCPM2，不并行下载；先 20 秒样片，OOM 或 RTF 不合格即停。

所有结果只作影子候选，不覆盖当前音频；通过 T9 的自然度、中英混读、长听疲劳、稳定性、时间戳、权利和成本七门后才可升级。
