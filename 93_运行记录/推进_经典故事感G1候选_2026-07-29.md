## 二、两条素材路线必须分开

### A. 当前优先：原创“经典短篇感”

- 可以学习的是功能：三秒反常、普通人的具体目标、一次加码、可见证据、必须付出的小代价、动作式结尾。
- 不可以迁移的是现成作品的人物关系、事件顺序、关键道具组合、标志台词、独特反转、标题或镜头。
- 国家版权局公开材料把“借鉴思想后形成自己的表达”与改头换面的洗稿区分开；本文采取更保守的项目规则：连可识别的完整因果链也不迁移。
- 当前六条没有使用任何《故事会》《意林》、网文、短剧、漫画或 UP 视频作为故事底稿。

### B. 后续备选：已核验古典原作 / 民间文学

- **古典原作路线**：先确认作者、成书年代、所依据底本和财产权保护期，再从国家图书馆古籍平台等可追溯馆藏核对原文。现代点校、白话译写、插图、导读、表演、录音和影视改编是另一层权利，不能因为古代原作年代久远就直接复制。
- **民间文学路线**：国家级非遗名录能证明白蛇传、梁祝、孟姜女、董永等属于代表性民间文学项目，但“列入非遗”不等于任何现代文本、讲述版本、传承人表演或影像都可自由使用。著作权法对民间文学艺术作品另有专门立法授权，最高法公开意见同时强调利用民间素材应说明来源；本项目因此要求逐案记录地域版本、材料来源、社区/传承语境和新增表达。
- **当前处置**：民间/古典路线只进入“待核权研究池”，不与这六个原创 G1 候选混用。没有完成 `原作—底本—现代整理—视觉/声音素材` 四层权利清单前，不进入脚本生成。

[INFERRED] 古代原作可能已经超过现行法规定的财产权保护期，但具体项目仍需逐件核验；“网上可读”“国家平台开放阅览”“属于非遗”都不能单独等同于可商用授权。

## 三、六个原创候选卡

### GS01 · 每份复印件里那张白纸

- **一句钩子**：`这家店每份复印件都多一张白纸，最忙那天，学徒终于把它省掉了。`
- **核心因果链**：店主习惯在不同客人的材料间插一张白纸 → 新学徒认为浪费，忙时取消 → 两摞材料在取件台滑到一起，一页差点被另一位客人带走 → 店主用过去那张白纸的位置立即识别边界并叫停 → 两人改用可反复使用的彩色隔页卡，保留规则但不再多耗纸。
- **反转**：白纸不是复印错误，也不是无意义的赠品，而是一条保护陌生人材料边界的低技术防线。
- **情绪承诺**：不靠催泪，兑现“真正的体面常藏在不起眼的流程里”。
- **漫画画格潜力**：全格用密集纸堆制造忙乱；细节格拍白纸边缘、两摞材料错位和伸手叫停；冲击格只留一张纯白纸与两侧不同颜色的夹子。可在 6 格内完成，文字内容全部虚化，避免生成个人信息。
- **原创风险检查**：普通“白纸/隔页”属于公共生活素材，但本条的学徒删规则、险些混单、改成循环隔页卡的顺序必须保留创作版本证据；不展示真实证件、号码、店名或客户经历，不宣称来自真实案例。2026-07-29 精确标题初筛未见明显同题命中，但不是穷尽式查重。

### GS02 · 饭馆里永远没人坐的“第零桌”（首选）

- **一句钩子**：`饭馆每天都有“第零桌”的账，可店里根本没有零号桌。`
- **核心因果链**：新记账员连续发现第零桌有菜却无收款 → 他怀疑有人长期免单或偷偷抹账 → 厨师拿出记录：做错、上迟、漏看“少辣”等需要重做的菜都记在第零桌，不向客人收费，也不从账上消失 → 当天老板自己漏看备注 → 老板重做一份，并在第零桌责任栏写下自己的名字。
- **反转**：第零桌不是特权桌，也不是逃单漏洞，而是饭馆专门留给“自己的错误”的账。
- **情绪承诺**：观众先怀疑不公，最后看到一个人愿意把自己也放进规则；收束在责任，不做训话。
- **漫画画格潜力**：第一页账本“0桌”作钩子；空餐厅里没有零号桌作空间证据；错单票、重做菜、老板落笔三组细节逐次加码；冲击格是责任栏里出现老板姓名。单场景、角色少，6–8 格即可成立。
- **原创风险检查**：不映射真实饭馆、平台或劳动制度，不把“第零桌”包装成行业惯例；不展示可识别账单。它与 C01 都触及责任，但 C01 是“客户想用漂亮语言替代行动、写作者退款”，本条是“店内用可核对账目承担自己的操作错误”，人物、道具、冲突和反转均不同。精确标题初筛未见明显同题命中，完整因果链仍须在 G2 定稿后复查。

### GS03 · 两家小店共用一块“售罄”牌

- **一句钩子**：`对门两家店做了十年“对手”，却只做了一块“本店售罄，对门还有”的牌子。`
- **核心因果链**：两家店客群相近，谁先卖完就把共享牌挂在自家门口，箭头指向对门 → 新帮工怕把今天的客人送走，悄悄收起牌子 → 几位顾客看到售罄后直接离开整条街 → 店主解释，牌子不是替对手打广告，而是让顾客下次还愿意来这条街 → 他重新挂出；下一次对门先售罄，箭头反向指回来。
- **反转**：共享牌不是庆祝“我卖完了”，而是主动把眼前生意让给对门，以保住两家共同的长期信任。
- **情绪承诺**：给出一种不天真也不算计的同行关系；好意有现实逻辑，不靠一方牺牲到底。
- **漫画画格潜力**：左右对称的两间店天然适合分格；箭头牌可作为连续性锚点；细节格展示牌被藏进柜台；末格牌翻面，完成视觉回环。适合横向调度后裁成竖屏上下漫画格。
- **原创风险检查**：不使用真实品牌、街区或经营数据，不声称真实事件；同行互助是公共母题，具体“双面箭头牌—帮工藏牌—整条街流失—反向回挂”链条必须独立留档。与 O01 的七位陌生人归还同一把伞不同，本条只有两个固定经营者，冲突是长期协作与短期得失，不是物件接力。

### GS04 · 修鞋匠把补好的鞋又拆开了

- **一句钩子**：`客人已经说“看不出补过”，修鞋匠却把整圈新线又拆了。`
- **核心因果链**：赶时间的客人验收外观后准备离开 → 学徒松口气，说里面有一枚钉子“应该碰不到脚” → 师傅复查，发现钉尖在受力后可能顶起 → 他叫回客人说明延误，拆掉刚完成的鞋底并重做 → 客人问外面明明很好看为何非拆不可，师傅只把取出的短钉放在白纸上，不说大道理。
- **反转**：返工不是因为人人看得见的线缝歪了，而是因为一个交货后可能永远没人知道的隐患。
- **情绪承诺**：手艺的分量落在“无人看见处也不糊弄”，不靠贫困身世或顾客报恩。
- **漫画画格潜力**：成品鞋的完整全格与钉尖微距形成强反差；时钟、拆线、白纸上的钉子形成三次视觉加码；末格可以只留重新缝合的鞋底，不拍长篇对话。
- **原创风险检查**：工匠良心是公共母题，不能套用现成寓言或“祖传名匠”文本；钉子位置和维修过程只作叙事证据，不给危险操作教程。它和 C01 都含“主动承担成本”，但没有代写、退款、道歉或受害者原谅结构；若两条同轮生产，仍应错开以免责任主题疲劳。

### GS05 · 搬家车为什么为一个空花盆多跑一趟

- **一句钩子**：`搬家车已经开出两条街，师傅却为了阳台上一个空花盆掉了头。`
- **核心因果链**：客户清点完家具，明确说阳台空盆不要了 → 搬家师傅搬走最后一箱时看见盆里一块写着“三月见”的旧木牌，没有擅自翻土 → 车开出后他把照片发给客户再次确认 → 客户想起远行的女儿入冬前种过球根，改口请他带上 → 师傅返回，空盆被放进新家窗边；春天只用一格新芽兑现结果。
- **反转**：看起来什么都没有的花盆，装着的不是贵重物，而是一件尚未发生、但有人答应等待的事。
- **情绪承诺**：轻度怀旧但不诉诸死亡；把“多问一次”写成尊重，而不是替别人决定物品价值。
- **漫画画格潜力**：空阳台、车尾关闭、木牌微距、掉头路线、窗边新芽可构成清晰五段；冬灰到春绿提供天然色彩反转。没有复杂口型和多人连续表演。
- **原创风险检查**：不把搬家人员写成擅自翻找物品的英雄；关键动作是拍照询问并由客户决定。空盆/球根属于常见生活意象，具体“客户主动弃置—木牌提醒—二次确认—掉头—春芽”链条须保存独立草稿。与 O01/F02/C01 均无角色、设定或反转重合；与库内家庭旧物类题目有轻度审美邻近，排期时不要紧跟老照片、旧衣等题材。

### GS06 · 演出开始前，两把椅子为什么斜对着墙

- **一句钩子**：`演出开始前，志愿者把第一排两把椅子斜着转向墙，身后立刻有人说“不尊重舞台”。`
- **核心因果链**：新志愿者把“摆歪”的椅子全部转正 → 两位使用手语的观众入场后，正对舞台的位置无法同时看清侧前方的手语翻译和主要表演区域 → 负责人没有替他们决定，而是当面询问偏好并按其选择把座位斜放 → 新志愿者在地面补上可移动标记，下一场仍先询问，不把角度固化成唯一答案。
- **反转**：椅子斜放不是背对舞台，而是让观众能同时看见舞台与手语；真正重要的不是“摆得整齐”，而是当事人能选择怎么看。
- **情绪承诺**：不是健全人施予便利的感动叙事，而是一个人发现“我以为的整齐”不等于别人可用。
- **漫画画格潜力**：俯视全格直接展示视线几何；椅子被转正/再斜放形成动作反复；手语只画手部与视线，不让生图承担长句；冲击格可用两条视线同时落在舞台和翻译者上。
- **原创风险检查**：不得把两位角色当励志或感动工具，也不能声称所有聋人、重听者或手语使用者偏好相同座位。G2 前需要核验无障碍表达并由真实相关使用者复看；本条是虚构小型演出，不引用具体场馆规则。精确标题初筛未见明显同题命中，但无障碍事实与表现仍需专项复核。

## 五、G1 以后才执行的最小验证

1. 只对通过 G1 的一条建立 `角色—目标—障碍—证据—代价—结尾动作` 六格灰度稿。
2. 让未读故事的人看无旁白画格，只回答：`开头哪里反常？`、`反转证据是什么？`、`主角具体付出了什么？`。三问有一问答不清就退回因果链，不先加配音和运镜。
3. 最终标题、关键道具组合、三段因果和结尾动作再做一次公开碰撞初筛；检索不到只记为 `[INFERRED] 未见明显碰撞`，不写“保证原创”。
4. 通过 G2 后再决定全格/细节格/冲击格层次和运镜；不会让视觉升级反向改写已批准的因果。
5. 每条持续标注 `虚构故事 / 剧情演绎 / AI 生成内容`，并保存命题卡、版本差异、提示词、生成日期与素材权利清单。
