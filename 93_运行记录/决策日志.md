## 2026-07

**2026-07-26 ｜ 系统重构 v2.0 ｜ 依据：AI 自媒体生态调研**

在 v0.1 的四阶段流水线骨架上做了六处结构性升级：

1. **新增 `91_知识库/`**，把调研结论沉淀为 AI 生成时的**硬约束**而非参考读物
   （K1 钩子公式 / K2 平台规格 / K3 叙事结构 / K4 数据诊断 / K5 生图一致性 / K6 合规 / K7 选题雷达）
2. **新增 `.claude/skills/` 六个 Agent Skill**，把 README 里的散文流程变成可触发、可并行调度的技能
3. **新增 `00_账号定位/角色资产库/`**，用"定妆照 + 角色锁 + 风格锁 + 线索追踪"三层机制解决 AI 插画角色漂移
4. **新增 `92_工具箱/` 五个脚本**，把生图、配音、字幕对齐、视频合成、剪映草稿变成一条命令
5. **选题打分从三维改四维**，新增「差异」维度
   —— 依据：前三维（契合/需求/成本）会系统性偏向"安全但同质"的选题，差异维度是唯一能把蓝海选题顶上来的机制
6. **明确信任域划分**：所有需要平台登录态的动作（发布、抓取）只在本地 Windows 执行，云端会话一律不碰
   —— 依据：跨境 IP + 代理出口访问平台有封号风险；公众号 API 还需要固定 IP 白名单

同时确定的技术路线取舍：

| 决策 | 选择 | 为什么 |
|---|---|---|
| 生图 | Gemini / Nano Banana API 为主，GPT 网页补关键图 | 官方支持 4-5 个角色参考图、原生 9:16；GPT 官方承认角色一致性不稳定，只适合补图 |
| 剪辑 | ffmpeg 批量为主，剪映草稿只做爆款精修 | 剪映 7+ 封了自动导出，每条手动点导出在批量时是纯线性人力 |
| 配音 | edge-tts | **自带词级时间戳**（本地开源方案普遍不给），字幕对齐白送。免费只是附带好处 |
| 知识线配图 | HTML 排版截图，**不用扩散模型** | 扩散模型画中文字永远是残的；HTML 排版文字锐利、零成本、完全可重复 |
| 发布 | 小红书 MCP + Wechatsync + 公众号草稿箱；抖音/视频号手动 | 浏览器自动化对抗风控是易碎件，不把核心链路押在上面 |
| 工作流平台 | 不上 n8n / Dify / Coze | 已有 Claude 做编排，再套一层只多一个要维护的中间件，且中文平台连接器基本空白 |

明确放弃：MediaCrawler（禁商用）、Spider_XHS（硬逆向签名迟早碎）、Postiz（零中文平台）、
IP-Adapter / InstantID / PuLID（停更且权重研究用途）、FLUX.2-dev（禁商用）。

## 2026-07-28 · 工作流 v2.1：运动、矩阵与语音

**运动**：取消“单图固定 3–6 秒、超过 8 秒必掉完播”的伪精确规则。按信息状态拆镜；复杂动作使用 `F0→必要 K→F1`，主体/环境/摄影机分栏，每镜最多一个强运动通道。先做确定性全片，只升级 2–3 个英雄镜；提示词写 `END FRAME LOCK` 不等于真实末帧绑定。

**矩阵**：先用一个孵化号测试“人间物证 / 明日来信 / 选择之后 / 故事实验室”，每单元至少 3 条，同平台同观察窗比较中位数，不生成跨平台万能分数。达到重复胜出、稳定受众承诺和 30 天原创库存后才讨论拆号。

**特征学习**：外部博主、《故事会》《意林》只用于学习受众承诺、钩子功能、因果节拍、镜头/声音语法；不下载、不保存逐字稿、不做换名/换职业/换时代改写。每个外部样本只产出一个可验证的抽象假设。

**语音**：edge-tts 从长期默认降为内部基线/回退。自然女声与中英混读分开盲测；本地先测 Qwen3-TTS 0.6B `Serena/Vivian`，VoxCPM2 仅作 8GB 显存边界实验，正式云后备优先预算受控的 Qwen3-TTS/CosyVoice。新引擎只做影子版，不覆盖已通过音频。

**工具与模板**：新增 T7–T11、K9/K10、矩阵实验/外部样本池、`matrix_tracker.py` 和 `zimeiti-matrix` Skill；`build_video.py` 兼容 motion plan v1/v2，并验证运动通道、英雄镜预算和 endpoint binding。
