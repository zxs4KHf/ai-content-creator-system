## 2026-07

**2026-07-26 ｜ 系统重构 v2.0 ｜ 依据：AI 自媒体生态调研**

在 v0.1 的四阶段流水线骨架上做了六处结构性升级：

1. **新增 `91_知识库/`**，把调研结论沉淀为 AI 生成时的**硬约束**而非参考读物
   （K1 钩子公式 / K2 平台规格 / K3 叙事结构 / K4 数据诊断 / K5 生图一致性 / K6 合规 / K7 选题雷达）
2. **新增 `.claude/skills/` 六个 Agent Skill**，把 README 里的散文流程变成可触发、可并行调度的技能
3. **新增 `00_账号定位/角色资产库/`**，用"定妆照 + 角色锁 + 风格锁 + 线索追踪"三层机制解决 AI 插画角色漂移
4. **新增 `92_工具箱/` 五个脚本**，把生图、配音、字幕对齐、视频合成、剪映草稿变成一条命令
5. **选题打分从三维改四维**，新增「差异」维度
   —— 依据：前三维（契合/需求/成本）会系统性偏向"安全但同质"的选题，差异维度是唯一能把蓝海选题顶上来的机制
6. **明确信任域划分**：所有需要平台登录态的动作（发布、抓取）只在本地 Windows 执行，云端会话一律不碰
   —— 依据：跨境 IP + 代理出口访问平台有封号风险；公众号 API 还需要固定 IP 白名单

同时确定的技术路线取舍：

| 决策 | 选择 | 为什么 |
|---|---|---|
| 生图 | Gemini / Nano Banana API 为主，GPT 网页补关键图 | 官方支持 4-5 个角色参考图、原生 9:16；GPT 官方承认角色一致性不稳定，只适合补图 |
| 剪辑 | ffmpeg 批量为主，剪映草稿只做爆款精修 | 剪映 7+ 封了自动导出，每条手动点导出在批量时是纯线性人力 |
| 配音 | edge-tts | **自带词级时间戳**（本地开源方案普遍不给），字幕对齐白送。免费只是附带好处 |
| 知识线配图 | HTML 排版截图，**不用扩散模型** | 扩散模型画中文字永远是残的；HTML 排版文字锐利、零成本、完全可重复 |
| 发布 | 小红书 MCP + Wechatsync + 公众号草稿箱；抖音/视频号手动 | 浏览器自动化对抗风控是易碎件，不把核心链路押在上面 |
| 工作流平台 | 不上 n8n / Dify / Coze | 已有 Claude 做编排，再套一层只多一个要维护的中间件，且中文平台连接器基本空白 |

明确放弃：MediaCrawler（禁商用）、Spider_XHS（硬逆向签名迟早碎）、Postiz（零中文平台）、
IP-Adapter / InstantID / PuLID（停更且权重研究用途）、FLUX.2-dev（禁商用）。

## 2026-07-28 · 工作流 v2.1：运动、矩阵与语音

**运动**：取消“单图固定 3–6 秒、超过 8 秒必掉完播”的伪精确规则。按信息状态拆镜；复杂动作使用 `F0→必要 K→F1`，主体/环境/摄影机分栏，每镜最多一个强运动通道。先做确定性全片，只升级 2–3 个英雄镜；提示词写 `END FRAME LOCK` 不等于真实末帧绑定。

**矩阵**：先用一个孵化号测试“人间物证 / 明日来信 / 选择之后 / 故事实验室”，每单元至少 3 条，同平台同观察窗比较中位数，不生成跨平台万能分数。达到重复胜出、稳定受众承诺和 30 天原创库存后才讨论拆号。

**特征学习**：外部博主、《故事会》《意林》只用于学习受众承诺、钩子功能、因果节拍、镜头/声音语法；不下载、不保存逐字稿、不做换名/换职业/换时代改写。每个外部样本只产出一个可验证的抽象假设。

**语音**：edge-tts 从长期默认降为内部基线/回退。自然女声与中英混读分开盲测；本地先测 Qwen3-TTS 0.6B `Serena/Vivian`，VoxCPM2 仅作 8GB 显存边界实验，正式云后备优先预算受控的 Qwen3-TTS/CosyVoice。新引擎只做影子版，不覆盖已通过音频。

**工具与模板**：新增 T7–T11、K9/K10、矩阵实验/外部样本池、`matrix_tracker.py` 和 `zimeiti-matrix` Skill；`build_video.py` 兼容 motion plan v1/v2，并验证运动通道、英雄镜预算和 endpoint binding。

## 2026-07-28 · 语音路线 v2.2：参考锚、本地强模型与原创声线

**参考锚**：参考 UP 本人公开说明将音色线索指向 API 侧 `Podcast_girl`，参数基本默认。正式云 A/B 先用 MiniMax `get_voice` 查询真实可用 ID，再用 Speech 2.8 HD/Turbo 默认参数测同稿；不克隆 UP，也不把旧音色 ID 写死。

**本地升级**：首测从 Qwen3-TTS 0.6B 上调为 1.7B CustomVoice `Serena/Vivian`；本机只在单模型、batch=1、关闭其他 GPU 应用后仍实测 OOM 才降 0.6B。VoxCPM2 为第二候选，OOM 即退 VoxCPM1.5；CosyVoice3 做原创参考声的渲染对照。

**原创声线**：Qwen VoiceDesign / VoxCPM2 只用抽象属性设计原创女声，再由 Qwen Base、VoxCPM2、CosyVoice3 渲染；保存 prompt、seed、revision、许可和音频 hash。IndexTTS2 因许可表述冲突只做内部情绪研究，GPT-SoVITS 等到本人或签约女声数据后再进入。

**成本与安全**：MiniMax T10 三段 HD 估算约 0.13 元；系统音色先于 9.9 元的 Voice Design 激活。所有云调用默认 dry-run，Key 只读环境变量，执行必须同时确认计费与正向预算上限；新音频仍是影子版。

## 2026-07-28 · 生图许可纠错 v2.3

**更正旧结论**：2026-07-26 的“IP-Adapter / InstantID / PuLID 都停更且从根上不可商用、FLUX.2-dev 禁商用”是把维护状态、代码许可、权重许可、底模、依赖和输出条款混在一起的过度概括，现由 K5 的端到端许可表取代。

**当前边界**：通用非 FaceID IP-Adapter 不强制依赖 InsightFace，可在完整组件链放行后评估；InstantID、IP-Adapter-FaceID 与标准 PuLID 免费链因 checkpoint / InsightFace 权利未闭环，当前不进商业成片。FLUX 必须按准确型号区分：`[dev]` 免费权重不授权商业生产运行，但输出条款另算；`[klein]` 等型号另有许可证。

**执行规则**：任何生图链按 `代码 + 适配器/权重 + 底模 + 依赖权重 + 输出条款 + 输入素材权利 + 使用场景 + 核验日期` 留档；“开源”“Apache-2.0”或“最近没有提交”都不能单独替代结论。

## 2026-07-29 · 原创故事漫画解说 v2.4

**内容边界**：把“故事会式故事感”和漫画解说当成受众承诺与视觉语法，不把《故事会》《意林》、网文、漫画或其他 UP 的故事、画面、台词、声音拿来改编；生产素材只用原创、公版或明确授权内容。

**同片影子测试**：`build_video.py --frame-style comic` 保留故事、旁白、真实时轴、运动和字幕，只改变画格包装。`preview_comic_v2.mp4` 使用不裁切的 9:16 主画格，与全幅 `preview_v2.mp4` 并存，未获 G3 选择前不替换。

**方法**：按因果状态换格，常规大格/细节证据格/冲击格有明确主次；反转前先让旧判断成立，画面不提前泄底。外部漫画解说只产出一个可验证的抽象假设。

## 2026-07-29 · 语音执行安全合同 v2.5

**付费前 fail closed**：外部 TTS 价格不得低于仓库内最新官方价格快照，快照超过 30 天就阻止调用；必须先确认 ffmpeg/ffprobe、有限预算和本机环境变量 Key。分段成功后立即保存可校验 sidecar，失败重跑复用已付费片段，不从第一段重复调用。

**输出与权利**：云端和本地执行器默认不覆盖已有音频/manifest，只有显式 `--overwrite` 才允许替换；克隆音色必须同时确认声音权利并提供本地授权记录。Qwen 本地链只接受完整官方 1.7B CustomVoice safetensors、随仓 tokenizer 和可核验架构/内容指纹，并向加载器传 `local_files_only=True`。

**字幕门**：供应商支持词时间戳不等于适配器合同已验证。真实响应未解析前，单段超过 24 字且没有词时间就拒绝生成发布字幕，要求 stable-ts 后对齐；按字数机械切分只作预览/诊断。
