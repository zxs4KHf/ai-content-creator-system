## 技术

- 画面：确定性 Canvas 的 `render(t)`，无头 Chrome 逐帧取图，管道给 ffmpeg。见 `工具/capture.mjs`。
- 音效：程序合成，按作品写在作品文件夹里（例：`作品/喂/音频/`）。
- ffmpeg：`.tools/ffmpeg/`。`.tools/` 和 `.venv/` 不进 Git，也不要手动移动。
- 配音与生成：阿里云百炼，密钥只从环境变量读取。跑付费或按量模型前先查额度。
- 个人优先级、额度和账户情况放在不进 Git 的 `.context/LOCAL.md`。
