# K9 · 内容特征学习与账号矩阵实验

> 把外部优秀内容拆成可验证的抽象假设，把自家发布数据变成下一轮生产规则。完整研究与来源见 `93_运行记录/调研_故事题材与账号矩阵_2026-07-28.md`。

## 一、定义与边界

本项目把“蒸馏博主”统一称为**特征学习**：只学习受众承诺、钩子功能、信息缺口、因果节拍、情绪曲线、镜头语法、声音功能、CTA 和包装机制。

不得复制或近似替换：具体人物、关系、目标、障碍、关键情节链、台词、标题、金句、标志构图、原画、视频片段、音乐、封面、Logo、口头禅、声线或账号身份。

《故事会》《意林》可作为“大众人物、单一冲突、因果清楚、短篇闭环、结尾余味”的机制类比，不能作为改写素材库。换名字、职业、时代或地点后重讲，仍不是原创。

## 二、先栏目孵化，再考虑拆号

冷启动先用一个孵化号测试四个栏目，每栏目至少 3 条：

| 栏目 | 受众承诺 | 优先发动机 | 生产约束 |
|---|---|---|---|
| 人间物证 | 普通物件替人说出没说出口的话 | 物件见证、动作接力 | 1–2 人、静物近景、克制声线 |
| 明日来信 | 还没发明的工具照见今天的选择 | 选择付费、规则例外 | 明确标虚构；AI 设定不冒充事实 |
| 选择之后 | 不讲道理，只呈现一次有代价的选择 | 普通职业、误解校正 | 尊重职业，不猎奇卖惨 |
| 故事实验室 | 展示故事如何从想法变成画面，包括失败 | 成片高光→方法→对比→改动 | B 站优先做成片+幕后，不只搬竖屏 |

首轮 12 条用于寻找“题材 × 受众承诺”，不是 12 个账号。只有同时满足以下门槛才考虑拆号：

- 至少 3 条进入最近 10 条前 20%，不是单条偶然爆；
- 观众能用一句稳定的话描述该栏目；
- 已备好 30 天 8–12 条互不重复的原创库存；
- 新号与母号的受众承诺、视觉和更新理由明确不同；
- 发布当日重新核验平台账号数量、实名与营利规则。

每个账号采用 `70% 核心承诺 / 20% 邻近实验 / 10% 幕后飞轮内容`。不得用多个账号重复发布、刷互动或制造虚假热度。

## 三、实验最小合同

先区分三种类型：

- `pilot`：只验证端到端流程，不能定义账号方向；
- `discovery`：比较不同栏目承诺的组合表现，只决定下一轮样本分配，不能归因给其中某个变量；
- `controlled`：其他项锁定，只改变一个变量，才允许形成因果假设。

每个实验必须有：

`experiment_id / hypothesis_id / experiment_type / account_id / platform / series / content_id / variant / changed_variable / fixed_variables / observation_window / primary_metric / safety_metric`

规则：

1. `controlled` 一次只设一个主要变量，其他生产项锁定；`discovery` 只能说“哪个组合值得继续测”，不能说某个元素导致胜出。
2. 每个变体至少 3 条后才判断方向；单条爆/扑不改永久规则。
3. 48 小时和 7 天各记录一次，禁止挑最好看的窗口。
4. 只在同平台、同观察窗、同形式内比较；不制造跨平台万能总分。
5. 样本不足 10 条时只看方向和本账号滚动中位数，不套行业阈值。
6. 平台后台没有的数据留空，不手算、不猜测。

用 `90_模板库/T7_账号矩阵实验卡.md` 设计实验，数据写 `01_想法库/矩阵实验数据.csv`，再用 `92_工具箱/matrix_tracker.py` 检查覆盖和分组中位数。

## 四、指标与决策

优先指标：

- 钩子：3 秒/前段留存；
- 叙事：平均观看时长、50% 留存、完播率；
- 情绪：转发率、收藏率；
- 社区：评论率、有效评论率；
- 系列：每千播放关注；
- 安全：举报、负反馈、打回/补标/限流、版权或声音权利投诉。

**延续：**同栏目 3 条中至少 2 条，在“观看”“转发或收藏”“关注”三组里有两组高于当批中位数，且无安全问题，则追加 3 条；下一条只继承一个胜出变量。

**爆点加码：**单条在留存与转发/收藏/关注至少两个维度同时进入最近 10 条前 20%，且评论在讨论内容而非错误或 AI 瑕疵，则 72 小时内规划：

- 一条同母题、不同人物/目标/障碍/结局的原创故事；
- 一条同结构、不同母题的原创故事；
- 一条幕后复盘。

7 天后若没有复现，不把偶然值写进永久规则。

**暂停：**同栏目连续 3 条在叙事与系列指标上都低于同形式中位数 70%，且有效评论无反向信号，则暂停一轮并保留数据。

**立即停更复审：**版权投诉、可识别真人、未标 AI/虚构、事实误导、未成年人风险、低俗猎奇、未授权声音/肖像或平台违规通知。安全失败不等待三条样本。

## 五、外部样本只记功能

外部样本使用 `90_模板库/T11_外部样本特征卡.md`，集中写入 `01_想法库/外部样本特征池.md`。只保存 URL、创作者（仅溯源）、观察时间和功能笔记；不下载原视频、不保存整段字幕、不抄逐字稿、不把脚本当“改写底稿”。至少记录：

- `audience_promise / title_mechanism / opening_0_3s`；
- `information_gap / conflict / causal_steps / turn_timing`；
- `payoff_type / ending_function`；
- `shot_grammar / audio_function / duration_and_density`；
- `public_signals`（带采样时间；后台不可见项留空）；
- `transferable_hypothesis`（只能一个变量）；
- `forbidden_to_copy / new_story_differences / rights_notes / next_experiment`。

## 六、原创防火墙

1. **研究去名词化：**只保留“普通劳动者”“关系修复”“延迟揭示”等功能词，具体姓名、职业组合、地点、标志物和台词不进入生成提示词。
2. **原创命题先行：**先写本项目要讨论的选择，再选择故事发动机；不得从某条外部剧情开始同义替换。
3. **八项差异审计：**主角身份、欲望、阻碍、代价、关键因果链、结局、视觉符号、语言均需独立创作。
4. **关键情节链审计：**创意或母题可能公共，但具有独创性的取舍、串联和整体安排仍可能受保护。
5. **生成前限制：**不得模仿具体作者/博主，不得复用样本人物、关系、事件顺序、结尾、台词、标题和构图。
6. **保留创作证据：**原创命题、版本差异、角色卡、分镜草图、模型/日期和授权清单进入内容目录；未经许可的完整作品副本不入库。

虚构故事必须显著标注“虚构故事 / 剧情演绎”，AI 画面、配音、脚本或视频按 K6 做可见标识和平台声明。不得包装成真人采访、现场拍摄或真实社会事件。

## 七、优先题材

当前能力与定位下优先：

1. 旧物/日常动作承载未说出口的话；
2. 近未来 AI 与普通人的微型选择；
3. 普通职业的一次有代价选择；
4. 家庭沟通与代际误解；
5. 城市轻奇幻、温和谜面和具体成长瞬间作为邻近实验。

社会热点改编、真实案件、真人秘闻禁做。民间故事/古典文本仅在核验原作、译本、改编本、插图、录音和数字版本权利后使用，冷启动暂缓。
