# K8 · AI 视频运动设计

> 适用于静态 animatic、Ken Burns、图生视频（I2V）、首尾帧和 V2V。
> 核心不是“让每张图都动”，而是让每个镜头完成一个信息状态变化，并能稳定落到可验收的目标状态。完整证据见 `93_运行记录/调研_分镜运镜方法论_2026-07-28.md`。

## 一、六条硬规则

1. **按信息状态拆镜，不按固定秒数拆镜。** 地点、主体、情绪极性、关键物或动作状态变化才是切镜依据；`3–6 秒`只能作为初始观察值，不能当质量标准。
2. **先完成确定性全片，再升级英雄镜。** 默认用静帧/Ken Burns 做可审片版，只升级收益最高的 2–3 镜。
3. **先锁意图与目标状态，再写动作和摄影机。** 没有叙事作用的运动删除。
4. **主体、环境、摄影机分开规划。** 每镜最多一个强运动通道；主体强动时摄影机降为锁机或轻跟随。
5. **文字声明不等于真实约束。** 只有末帧真的传入模型的 `lastFrame`/末帧槽，才能写 `endpoint_binding=actual_last_frame`；否则必须写 `prompt_only`，不得声称“已锁末帧”。
6. **失败必须可降级。** 同一配置连续失败 2 次，改变一个可归因变量或进入固定降级阶梯，不继续盲抽。

## 二、先拆语义节拍，再决定镜头数

把最终旁白按“观众此刻新知道了什么”拆成节拍，并标注：

`HOOK 钩子 / SETUP 建立 / ESCALATE 加压 / TURN 转折 / PAYOFF 回收 / ECHO 余韵`

每个节拍只回答一个视觉问题。出现以下任一情况时考虑拆镜：

- 地点、时间、叙事主体或情绪极性变化；
- 一个画面承担两个互不依赖的动作；
- 关键物必须被单独看清；
- 动作出现接触、遮挡、重心变化、方向反转；
- 旁白已经进入下一信息状态，而画面没有新的信息。

相邻镜承担相同功能、构图重心和信息时应合并。镜头时长由真实旁白时轴、辨认主体和读取字幕所需时间共同决定；单镜明显长于相邻镜时，必须写明停留理由或拆成建立/动作/反应镜。

## 三、一镜一卡：10 个必填字段

| 字段 | 必须回答的问题 |
|---|---|
| `INTENT` | 观众看完这一镜，认知或情绪发生什么变化？ |
| `START_FRAME (F0)` | 开始时可见的稳定状态是什么？ |
| `KEY_POSE (K)` | 是否存在必须经过的接触、遮挡、重心或方向变化点？ |
| `END_FRAME (F1)` | 最后 0.5–1 秒最值得记住的状态是什么？ |
| `SUBJECT` | 谁因为什么，按什么顺序动？ |
| `ENVIRONMENT` | 哪些环境元素微动，哪些必须锁死？ |
| `CAMERA` | 起点、路径、目标、速度曲线和停点是什么？ |
| `CONTINUITY` | 与前后镜必须延续哪些人物、道具、方向和光线？ |
| `METHOD` | 静帧 / Ken Burns / 单首帧 I2V / 首尾帧 / V2V / 硬切？ |
| `ACCEPTANCE` | 哪些错误一票否决，失败回退到什么？ |

详细制作卡使用 `90_模板库/T8_运动镜头卡.md`。缺 `INTENT / F0 / F1 / METHOD / ACCEPTANCE` 的镜头不得进入随机视频生成。

### 3.1 目标状态倒推

1. 写 `INTENT`。
2. 设计能独立表达主要信息的 `F1`。
3. 倒推与 `F1` 属于同一空间、同一因果链的 `F0`。
4. 若有接触建立/解除、明显遮挡、重心转移、方向反转、身份易漂移或大视角变化，设计 `K`。
5. 复杂动作拆为 `F0 → K`、`K → F1` 两段，K 作为共享边界帧。
6. 最后才写摄影机；摄影机服务于揭示或强调，不能替代缺失的动作逻辑。

### 3.2 动作因果链

人物动作统一写成：

`触发 TRIGGER → 感知 PERCEIVE → 预备 PREPARE → 主动作 EXECUTE → 落稳 SETTLE`

接触动作必须可看到 `接触前 / 接触成立 / 接触后` 三态。一个短镜只保留一个主要动作目标，并在末段留出稳定区；当前可用末段约 15%–20% 作为待验证起点，不得包装成通用规律。

## 四、三条运动通道与摄影机语法

逐镜分别记录强度 `0 静止 / 1 微 / 2 中 / 3 强`：

- `S`：主体动作；
- `E`：环境运动；
- `C`：摄影机运动。

最多一条为 `3`；若 `S=3`，则 `C≤1`。强主体动作与强运镜不得同时争抢注意力。

摄影机字段固定写：

`起点景别与方位 → 路径类型与方向 → 是否跟随 → 目标景别与重心 → 速度曲线 → 落稳位置`

术语必须准确：

- `pan / tilt`：摄影机固定点旋转；
- `dolly in / out`：摄影机实体前后移动；
- `tracking`：跟随主体；
- `orbit / arc`：绕主体走弧线；
- `zoom`：改变焦距，不等于 dolly。

单镜只保留一条主路径。不得把穿越、180°旋转、推近、环绕和拉焦堆在同一短镜里。

确定性 Ken Burns 必须记录 `mode / amount / ease / settle_ratio`；其中 `settle_ratio` 表示“前多少比例仍在推进运动”，例如 `0.82` 表示前 82% 运动、后 18% 保持稳定，不是稳定段本身占 82%。后续需要精确构图时再记录归一化的起止裁切坐标。`3%–6%` 缩放变化是本项目微运动的初始实验值，脸、手、字幕安全区漂移时继续减小。

## 五、方法选择与固定降级

| 方法 | 首选场景 | 主要风险 | 失败回退 |
|---|---|---|---|
| 静帧/硬切 | 信息强、身份/文字必须绝对稳定 | 活度低 | 构图切换、音效或 Ken Burns |
| Ken Burns | 旁白驱动、物件/环境镜、情绪停留 | “滑屏感” | 减幅、换方向或静帧 |
| 单首帧 I2V | 光影、雨尘、眨眼、简单动作 | 无法精确落到指定结尾 | 简化动作、清理首帧、退 Ken Burns |
| 首尾帧/关键帧 | 必须从 A 落到 B | 两端差异过大时中间失真 | 插 K 拆两段，仍失败则硬切 |
| V2V | 动作节奏或摄影机轨迹比画风更重要 | 底片抖动和大幅修改导致漂移 | 稳定/简化底片，或退 I2V |

固定修复阶梯：

`修首帧缺陷 → 简化提示词 → 删除一个运动通道 → 降低幅度 → 插入 K/拆镜 → 换 V2V → 回退 Ken Burns/静帧`

每次重试只改变一个变量，并记录模型/版本、输入帧、提示词、参数/seed、成本、失败原因和选择结论。已花费成本不是接纳坏镜头的理由。

## 六、连续性账本

每个场景至少记录：

- `SCREEN_DIRECTION`：人物朝向、进出画方向；
- `EYELINE`：视线对象及屏幕位置；
- `HAND/PROP`：道具在哪只手、状态、朝向和数量；
- `POSITION`：人物相对位置与遮挡；
- `LIGHT`：主光方向、昼夜和天气；
- `WARDROBE/IDENTITY`：服装、年龄、发型和识别特征；
- `CAMERA_SIDE`：人物关系轴的哪一侧；
- `BOUNDARY_FRAME`：上一镜末帧与下一镜首帧如何接合。

默认继承上一镜；只有剧情明确要求时才允许变化，并写明变化原因。减少模型必须重建的不可见空间，通常比堆提示词更能保持连续性。

## 七、逐镜 QA

每条动态镜至少检查 `0% / 25% / 50% / 75% / 100%` 五帧，并额外检查接触、遮挡、方向反转时刻。终审同时进行：

- 静音正常速观看；
- 正常声画观看；
- 0.5 倍速和关键点逐帧；
- 相邻镜边界检查。

一票否决项：人物身份/服装漂移、肢体或接触错误、道具/背景拓扑变化、文字变形、自动切镜/瞬移、方向或跳轴错误、未完成动作硬切、随机呼吸式抖动。

动态镜只有在**比确定性基线更好**且通过验收时才能替换；否则保留 Ken Burns/静帧基线。

## 八、嵌入 G1 / G2 / G3

### G1：视觉可行性

记录 3 个关键视觉 moment、复杂接触/大视角风险、成本层级 `A 确定性 / B 少量 I2V / C 关键帧或 V2V`，以及回退后题目是否仍成立。

### G2：冻结叙事和英雄镜

完成语义节拍表、逐镜意图、连续性账本和最多 2–3 个英雄镜。用真实旁白做低清 animatic。G2 通过后冻结台词、节拍和英雄镜意图，技术重试不得偷偷改剧情。

### G2 → G3：先基线、后升级

`真实旁白时轴 → 静态 animatic → 节奏 QA → Ken Burns 全片 → 英雄镜小样 → 五点/接触帧 QA → 合格才替换 → 声画 QA`

### G3：运动质量四问

1. 运动是在强化 `INTENT`，还是只增加热闹？
2. 任一帧是否出现身份、手部、道具、背景或文字错误？
3. 相邻镜的视线、方向、动作和光线是否连续？
4. 关掉声音能否理解动作，闭眼只听声音是否节奏自然？

G3 仍由人最终裁决；逐镜重试和技术降级不新增人工审批门。
