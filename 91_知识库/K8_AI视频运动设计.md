# K8 · AI 视频运动设计

> 适用于静态分镜动效、图生视频和首尾帧视频。核心不是“让画面动起来”，而是让动作与摄影机自然走向一个明确的目标状态。

## 一、先定终点，再反推过程

每个镜头先锁定最后 0.5–1 秒要稳定呈现的目标画面，再回答：

1. 主体最后是什么姿态、视线和位置？
2. 什么事件触发了这个结果？
3. 身体各部分按什么顺序完成动作？
4. 摄影机从哪里进入、经过哪里、最终停在哪里？

目标画面不是突然贴上的静帧，而应是前面所有动作发展的最后一步。

## 二、双参考职责必须分开

- **构图参考**：控制人物位置关系、景别、观看方向、光线和最终画面。
- **角色参考**：控制脸、体型、颜色、服装和唯一识别特征。

不得只给角色参考而让模型临时发明构图，也不得只给构图参考而放弃角色一致性。

## 三、人物动作写成因果链

不要写：`人物转身`。

应写：`门外传来声音 → 眼睛先移向声源 → 头部转动 → 肩膀与躯干跟随 → 脚步调整重心 → 在目标姿态稳定停住`。

规则：

- 一个 4–6 秒镜头只保留一个主要动作。
- 先动小关节/视线，再动头肩和躯干，最后移动重心。
- 动作必须在镜头结束前完成，最后保留稳定区。
- 不让角色一边完成复杂动作，一边承担激烈运镜。

## 四、摄影机写成飞行路线

把摄影机想成一架有惯性的 FPV 无人机，完整描述：

`起点景别/机位 → 进入方向 → 穿过的前景 → 转向或环绕 → 目标景别 → 减速 → 定格位置`

不要只写“快速推进”“镜头环绕”。至少写清起点、路径、终点与减速。

## 五、分层实现

| 层级 | 方案 | 适用 | 风险 |
|---|---|---|---|
| A | 带缓动与末段定格的 Ken Burns | 第一版、环境镜、静态叙事 | 角色最稳，动作有限 |
| B | 局部动效/视差/眨眼 | 雨、尘埃、光影、轻表情 | 需遮罩，控制范围 |
| C | 图生视频，目标帧倒推 | 转身、递书、开门等关键动作 | 角色和手部可能漂移 |
| D | 首尾帧或关键帧视频 | 必须精确落到目标构图的镜头 | 成本更高，需逐镜返工 |

先完成 A 层可审片版本；只把观感收益最高的 2–3 镜升级到 C/D，不全片盲目图生视频。

## 六、提示词结构

```text
END FRAME LOCK:
最后稳定画面的主体姿态、位置关系、景别、摄影机位置。

ACTION CAUSALITY:
触发事件 → 视线/小动作 → 头肩/躯干 → 重心/位移 → 完成目标姿态。

CAMERA FLIGHT PATH:
起点 → 进入 → 穿越前景 → 转向/环绕 → 减速 → 终点。

TIMING:
总时长；主要动作完成时间；最后稳定区时长。

LOCKS:
IDENTITY LOCK + STYLE LOCK + 不能变化的物件和背景。
```

## 七、自检

- [ ] 最后一帧构图在生成前已经确定
- [ ] 动作有触发原因，不是突然发生
- [ ] 摄影机有起点、路径、终点和减速
- [ ] 最后 0.5–1 秒动作与镜头均稳定
- [ ] 一个镜头只有一个主要动作
- [ ] 角色锁、服装、道具和左右方向未漂移
- [ ] 静态转动态、动态转静态没有硬切感
