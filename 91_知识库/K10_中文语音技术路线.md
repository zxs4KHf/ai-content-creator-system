# K10 · 中文语音技术路线

> 面向 RTX 3060 Ti 8GB 的旁白、角色声音、字幕时间轴和账号声音资产。完整研究、许可与价格证据见 `93_运行记录/调研_中文语音技术路线_2026-07-28.md`。

## 一、生产原则

1. 已验证的 `edge-tts` 音频只作为内部基线/故障回退；第三方无 Key 批量商用授权与 SLA 不明确，不把“可免费调用”当成长期商用许可。
2. 新引擎先产同稿影子版，不覆盖已通过音频；质量、稳定性、许可、时间戳和总成本五项均不退化才可替换默认。
3. 本机 8GB 首测 Qwen3-TTS 0.6B；VoxCPM2 约 8GB 属显存边界，OOM 就退 VoxCPM1.5，不靠超售显存制造“成功”。
4. 云后备只使用条款清晰的正式服务与合法试用；不换号、轮换身份、共享密钥或绕限流“薅”额度。
5. 声音风格只抽象语速、停顿、能量、情绪弧和重音；禁止未经同意克隆真人声音。
6. **自然女声和中英混读是两项独立硬门。** 中文听感好不能抵消英文专名/短句的拼音腔；同一音色必须检查语言切换是否突兀、重音是否正确，必要时按语言分段并使用同一声音资产的多语种能力。

### 自然女声 + 中英混读候选

| 优先级 | 候选 | 女声特征 | 英文策略 | 当前判断 |
|---|---|---|---|---|
| P1 本地 | Qwen3-TTS 0.6B `Serena` | 官方描述为温暖、柔和的年轻女声 | 支持英文；中文是母语，英文必须单列盲测 | 故事线第一候选 |
| P1 本地 | Qwen3-TTS 0.6B `Vivian` | 明亮、略带锐度的年轻女声 | 支持英文；检查长句是否过亮或播音化 | 知识线/年轻叙事候选 |
| P2 本地 | VoxCPM2 Voice Design | 可用“年轻成年女性、低饱和、克制、有呼吸感、非播音腔”设计原创音色 | 官方覆盖 30 语言；同一设计声线做中英混读 | 表现力强，但 8GB 显存临界 |
| P2 本地 | CosyVoice 3 0.5B | 可控情绪、语速、方言 | 多语言，需本机验证中英切换 | Windows/显存未知，排在 Qwen 后 |
| P1 云 | 阿里 Qwen3-TTS / CosyVoice | 指令控制、设计或复刻；正式低价服务 | 优先单一多语女声；CosyVoice 可返回时间戳 | 用户配置正式密钥后做 3 段 A/B |
| 基线 | Ava / Emma Multilingual | Ava 更有表现力，Emma 更偏对话 | 英语母语，多语种；重点检查中文韵律 | 已生成本地试听，不直接视为长期商用授权 |

Qwen3-TTS 官方说明 0.6B CustomVoice 的 `Serena`、`Vivian` 均能说模型支持的任意语言，但建议使用各自母语以获得最佳质量。因此“支持英文”只代表可生成，不代表本项目已认可英文听感。

截至 2026-07-28 的官方价目显示，阿里 Qwen3-TTS/CosyVoice Flash 起价约 0.8 元/万字符并有合法试用额度；价格、额度和模型能力会变化，接入当天必须复核官方页面并开启预算上限/用完即停。

## 三、统一输出合同

替换 TTS 时不得丢掉“音频实际时长 + 逐词/逐字时间 + 可复现 manifest”：

```json
{
  "provider": "local:qwen3-tts",
  "model": "model-name",
  "model_revision": "pinned-snapshot",
  "voice_id": "project-voice-id",
  "consent_record": null,
  "text_sha256": "...",
  "audio_path": "...",
  "duration_sec": 0.0,
  "sample_rate": 24000,
  "timestamps_source": "provider|stable-ts|faster-whisper",
  "words": [{"text": "示例", "start": 0.0, "end": 0.4, "confidence": null}],
  "generation": {"seed": 42, "instruction": "克制、低声、叙事感", "reference_audio_sha256": null},
  "license_checked_at": "YYYY-MM-DD",
  "cost": {"currency": "CNY", "amount": 0.0, "billable_units": 0}
}
```

时间戳优先级：供应商原生 → stable-ts 后对齐（标 `best-effort`）→ faster-whisper 后对齐。禁止按字数平均摊时间。数字、英文、专名、多音字和情绪拖音必须人工抽查。

## 四、统一盲测门

使用 `90_模板库/T9_中文语音盲测模板.md`：

- 固定 3 类 45–75 秒片段：克制温暖、悬疑情绪弧、数字/年份/专名/中英混读压力；
- 每类 3 seed，之后连续 100 个短段稳定性测试；
- 自然度、情绪贴合、角色一致性、可懂度各 1–5，3 人盲评；只有 1 人时分时复评并标局限；
- 女声候选额外记录：气声是否机械、句尾是否规律下坠、长句是否“播音腔”、中英切换是否换人、英文重音/连读是否自然；
- 自然度、可懂度均值至少 4.0；数字/专名无关键错读；
- 抽 20 个词/字人工打点，时间戳目标 `median≤120ms、p95≤250ms`；
- 记录峰值显存、RTF、冷启动、失败率、人工修音分钟和实际成本；
- 连续 10 条影子运行后，才讨论替换默认。

## 五、声音资产权利

每个账号维护声音卡：`voice_asset_id / source / model_revision / design_prompt / seed / allowed_platforms / territory / term / commercial_rights / consent_record / retest / revocation`。

允许：平台明确授权音色、原创声音设计、本人录音、签约配音员或具有可验证授权的参考音。

禁止：未授权 UP 主、主播、演员、名人、朋友、客户或普通人声音；公开视频可听不等于允许训练、克隆、上传云端或商用。API Key 仅放环境变量/密钥存储，不写仓库、日志、manifest 或媒体元数据。

## 六、下一轮执行顺序

1. 冻结现有 72.27 秒旁白，不覆盖。
2. 先用 `T10_语音盲测基准.txt` 做四个无账号基线：`zh-CN-XiaoxiaoNeural`、`zh-CN-XiaoyiNeural`、`en-US-AvaMultilingualNeural`、`en-US-EmmaMultilingualNeural`；前两者看中文女声，后两者重点看中英混读。它们只作内部基线，不自动升级长期商用路线。
3. 在独立环境首测 Qwen3-TTS 0.6B 内置女声；本轮不自动下载大型权重。
4. 通过基础可行性后再测授权参考音；未授权真人声音不进入输入。
5. VoxCPM2 使用原创声音设计构造自然女声，单模型串行测显存，OOM 则退 VoxCPM1.5。
6. 需要云 A/B 时，用户自行完成账号、实名、付款和密钥设置；AI 只消费本机环境变量，设置单次/当日预算和最大重试。
7. 任何新路线只做影子版，经 G3 人工选择后才替换。

产品能力、价格、许可和免费额度具有时效性，采购或调用前必须重新核验官方一手资料。
