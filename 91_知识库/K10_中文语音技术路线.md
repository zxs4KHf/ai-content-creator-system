# K10 · 中文语音技术路线

> 面向 RTX 3060 Ti 8GB 的旁白、角色声音、字幕时间轴和账号声音资产。完整研究、许可与价格证据见 `93_运行记录/调研_中文语音技术路线_2026-07-28.md`、`93_运行记录/调研_高质量本地与开源TTS_2026-07-28.md` 与 `93_运行记录/调研_MiniMax与参考声音_2026-07-28.md`。

## 一、生产原则

1. 已验证的 `edge-tts` 音频只作为内部基线/故障回退；第三方无 Key 批量商用授权与 SLA 不明确，不把“可免费调用”当成长期商用许可。
2. 新引擎先产同稿影子版，不覆盖已通过音频；质量、稳定性、许可、时间戳和总成本五项均不退化才可替换默认。
3. 本机 8GB 首测 Qwen3-TTS 1.7B CustomVoice；若单模型、batch=1、关闭其他 GPU 应用后仍 OOM，再降 0.6B。VoxCPM2 约 8GB 属显存边界，OOM 就退 VoxCPM1.5，不靠超售显存制造“成功”。
4. 云后备只使用条款清晰的正式服务与合法试用；不换号、轮换身份、共享密钥或绕限流“薅”额度。
5. 声音风格只抽象语速、停顿、能量、情绪弧和重音；禁止未经同意克隆真人声音。
6. **自然女声和中英混读是两项独立硬门。** 中文听感好不能抵消英文专名/短句的拼音腔；同一音色必须检查语言切换是否突兀、重音是否正确，必要时按语言分段并使用同一声音资产的多语种能力。

## 二、当前路由

| 层级 | 方案 | 用途 | 进入生产前条件 |

### 自然女声 + 中英混读候选

| 优先级 | 候选 | 女声特征 | 英文策略 | 当前判断 |
|---|---|---|---|---|

| P1 本地 | Qwen3-TTS 1.7B `Vivian` | 官方内置中文女声，可用自然语言指令控制风格 | 支持英文；检查长句是否过亮或播音化 | 知识线/年轻叙事候选 |
| P1 云 | MiniMax Speech 2.8 HD 系统/原创设计女声 | 当前参考质量的直接正式 API 对照；支持情绪、停顿、语气词和逐词字幕请求 | `language_boost=auto` 后仍要单列英文门；首次真实响应前不声称词时间合同已打通 | 三段盲测按量成本约角级；原创音色激活另计 |
| P2 本地 | VoxCPM2 Voice Design | 可用“年轻成年女性、低饱和、克制、有呼吸感、非播音腔”设计原创音色 | 官方覆盖 30 语言；同一设计声线做中英混读 | 表现力强，但 8GB 显存临界 |
| P2 本地 | CosyVoice 3 0.5B | 可控情绪、语速、方言 | 多语言，需本机验证中英切换 | Windows/显存未知，排在 Qwen 后 |
| P1 云 | 阿里 Qwen3-TTS / CosyVoice | 指令控制、设计或复刻；正式低价服务 | 优先单一多语女声；CosyVoice 可返回时间戳 | 用户配置正式密钥后做 3 段 A/B |
| 基线 | Ava / Emma Multilingual | Ava 更有表现力，Emma 更偏对话 | 英语母语，多语种；重点检查中文韵律 | 已生成本地试听，不直接视为长期商用授权 |

Qwen3-TTS 官方说明 1.7B CustomVoice 支持 10 种语言和自然语言风格指令，内置音色可说模型支持的语言，但仍建议使用各自母语以获得最佳质量。因此“支持英文”只代表可生成，不代表本项目已认可英文听感。

截至 2026-07-29 的官方价目显示，阿里北京地域 `qwen-audio-3.0-tts-plus` 为 1.4 元/万字符、`cosyvoice-v3.5-plus` 为 1.5 元/万字符，CosyVoice 3.5 Flash 与 Qwen3-TTS Instruct Flash 为 0.8 元/万字符。它们必须与 MiniMax HD 同稿盲测；官方“高表现力”描述不是本项目听感结论。合法试用仅使用控制台实际显示额度并开启用完即停。

同日 MiniMax 中国开放平台按量价为 Speech 2.8 HD `3.5 元/万字符`、Turbo `2 元/万字符`；计费规则为汉字 2 字符、其他字符 1 字符。T10 三段当前估算 374 计费字符，即 HD 约 `0.1309 元`。音色设计试听按 `2 元/万字符`，设计音色第一次正式用于 T2A 时另收 `9.9 元/音色`。价格与活动会变化，实际调用仍以执行当天官方页和脚本 dry-run 为准。

参考 UP 本人在公开视频评论中把音色线索指向 API 侧 `Podcast_girl`，并称参数基本保持默认；该 ID 不在当前静态官方清单，不能写死。正式测试先用 `tts_minimax.py voices` 调官方 `get_voice` 查询：若账号实际返回就先测它；否则依次测当前官方温暖/柔和女声，再进入原创 Voice Design。第一轮保持速度、音量、音高默认，不同时叠加情绪、呼吸标签和后期。

## 三、统一输出合同

替换 TTS 时不得丢掉“音频实际时长 + 逐词/逐字时间 + 可复现 manifest”：

```json
{
  "provider": "local:qwen3-tts",
  "model": "model-name",
  "model_revision": "pinned-snapshot",
  "voice_id": "project-voice-id",
  "consent_record": null,
  "text_sha256": "...",
  "audio_path": "...",
  "duration_sec": 0.0,
  "sample_rate": 24000,
  "timestamps_source": "provider|stable-ts|faster-whisper",
  "words": [{"text": "示例", "start_ms": 0, "end_ms": 400, "confidence": null}],
  "generation": {"seed": 42, "instruction": "克制、低声、叙事感", "reference_audio_sha256": null},
  "license_checked_at": "YYYY-MM-DD",
  "cost": {"currency": "CNY", "amount": 0.0, "billable_units": 0}
}
```

时间戳优先级：供应商原生 → stable-ts 后对齐（标 `best-effort`）→ faster-whisper 后对齐。禁止按字数平均摊时间。数字、英文、专名、多音字和情绪拖音必须人工抽查。

## 四、统一盲测门

使用 `90_模板库/T9_中文语音盲测模板.md`：

- 固定 3 类 45–75 秒片段：克制温暖、悬疑情绪弧、数字/年份/专名/中英混读压力；
- 每类 3 seed，之后连续 100 个短段稳定性测试；
- 自然度、节奏/停顿、情绪弧、声线一致、咬字/专名、英文听感和长听耐受各 1–5，3 人盲评；只有 1 人时分时复评并标局限；
- 女声候选额外记录：气声是否机械、句尾是否规律下坠、长句是否“播音腔”、中英切换是否换人、英文重音/连读是否自然；
- 自然度、咬字/专名、英文听感均值分别至少 4.0；数字/专名无关键错读；
- 抽 20 个词/字人工打点，时间戳目标 `median≤120ms、p95≤250ms`；
- 记录峰值显存、RTF、冷启动、失败率、人工修音分钟和实际成本；
- 连续 10 条影子运行后，才讨论替换默认。

## 五、声音资产权利

每个账号维护声音卡：`voice_asset_id / source / model_revision / design_prompt / seed / allowed_platforms / territory / term / commercial_rights / consent_record / retest / revocation`。

允许：平台明确授权音色、原创声音设计、本人录音、签约配音员或具有可验证授权的参考音。

禁止：未授权 UP 主、主播、演员、名人、朋友、客户或普通人声音；公开视频可听不等于允许训练、克隆、上传云端或商用。API Key 仅放环境变量/密钥存储，不写仓库、日志、manifest 或媒体元数据。

## 六、下一轮执行顺序

1. 冻结现有 72.27 秒旁白，不覆盖。
2. 先用 `T10_语音盲测基准.txt` 做四个无账号基线：`zh-CN-XiaoxiaoNeural`、`zh-CN-XiaoyiNeural`、`en-US-AvaMultilingualNeural`、`en-US-EmmaMultilingualNeural`；前两者看中文女声，后两者重点看中英混读。它们只作内部基线，不自动升级长期商用路线。
3. 先用 `tts_minimax.py` 对 Speech 2.8 HD 做不联网 dry-run；账号与 Key 就绪后，以 `≤1 元`硬上限跑系统女声 T10 三段，得到参考质量直接对照。
4. 用 `tts_qwen_local.py` 先做离线 preflight/dry-run，再在独立环境首测 Qwen3-TTS 1.7B CustomVoice；执行器只接受本地目录并禁止自动下载。仅在显存实测失败时降 0.6B。
5. 通过基础可行性后，用 Qwen VoiceDesign/VoxCPM2 设计原创女声，再让 Qwen Base、VoxCPM2、CosyVoice3 渲染同一合法声线；未授权真人声音不进入输入。
6. VoxCPM2 单模型串行测显存，OOM 则退 VoxCPM1.5；CosyVoice3 优先 WSL2。
7. 需要云 A/B 时，用户自行完成账号、实名、付款和密钥设置；AI 只消费本机环境变量，设置单次/当日预算和最大重试。MiniMax 与 DashScope 适配器均已具备离线安全骨架，但首次真实响应、实际音色 ID、费用回执和词时间字段通过合同测试前仍只做影子候选。
8. 任何新路线只做影子版，经 G3 人工选择后才替换。

产品能力、价格、许可和免费额度具有时效性，采购或调用前必须重新核验官方一手资料。
