## 一、三层一致性机制（必须全做，缺一层就漂）

### 第 1 层：角色基准图（Character Sheet / 定妆照）
先生成一张角色三视图定妆照，**存进 `00_账号定位/角色资产库/`**，之后每一张分镜都把它作为参考图输入。

### 第 2 层：线索追踪（Clue Tracking）
故事里反复出现的物件（一把伞、一只猫、一个杯子）登记为 clue，**每次生图提示词自动注入其固定描述**。物件比人脸更容易保持一致，且是叙事的锚。

### 第 3 层：风格锁（Style Lock）
一段固定的风格后缀，**所有分镜原样复制，一个字都不改**。

> **常见错误**：只锁角色不锁风格。结果 12 张图人是同一个人，画风各异——比人脸漂移更毁片。

## 二、角色设定块模板（填空即用）

```
【CHARACTER LOCK · 角色锁】
Identity : 一句话身份（年龄段 / 性别 / 气质）
Face     : 脸型 + 眼型 + 眉 + 鼻 + 唇（各一个形容词，不要堆砌）
Hair     : 长度 + 发型 + 颜色 + 刘海（必须精确，头发是漂移重灾区）
Mark     : ★ 1-2 个唯一识别特征（痣 / 疤 / 雀斑 / 眼镜 / 耳钉）—— 一致性的锚
Wardrobe : 上衣 + 下装 + 鞋 + ★1 个标志性配饰（颜色写死）
Build    : 身高体态（1 个词）

【STYLE LOCK · 风格锁】（每张图原样复制）

【NEGATIVE · 负面】（Gemini 用正向陈述，SD/Qwen 用负面框）
```

### 真实填好的例子（可直接改用）

```
【CHARACTER LOCK】
A Chinese woman in her late twenties, quiet and slightly weary.
Oval face, single eyelids, thin straight eyebrows, small nose, pale lips.
Shoulder-length straight black hair with blunt bangs.
A small mole under her right eye.
Faded indigo denim jacket over a plain white tee, black jeans, white canvas shoes,
and a red woven bracelet on her left wrist.
Slim, average height, slightly hunched posture.

【STYLE LOCK】
Style: soft gouache children's-book illustration, warm muted palette of dusty blue and amber,
visible paper grain, clean confident line work, gentle rim light,
cinematic vertical composition with generous negative space at the top.
No text, no watermark, no signature, no logo.

【NEGATIVE】
Avoid: extra fingers, deformed hands, multiple people, changed hairstyle,
different clothing, photorealistic skin, harsh contrast, text overlays, borders.
```

### 两条铁律（来自 Black Forest Labs 官方提示词方法论，对所有模型通用）

1. **用具体描述替代所有代词。** 写 `The woman with shoulder-length black hair`，绝不写 `her`。
   > 官方原文：*"Common mistake: Using vague references like 'her' instead of 'The woman with short black hair'"*
2. **显式写出要保留什么。**
   > 官方原文：*"If the model is changing elements you want to keep unchanged, be explicit about preservation in your prompt."*

### ⚠️ Gemini 没有负面提示词参数

Google 官方提示词指南**完全没有负面提示词**这个概念，方法论是**正向富描述**。
→ 对 Gemini，把负面写成正向陈述：`her hands are relaxed and clearly visible with five fingers` 优于 `no extra fingers`。
→ SD / Qwen 才用真正的负面提示框。

## 三、定妆照工作流（7 步，一个角色只做一次）

```
第 1 步  文字定稿
        把 CHARACTER LOCK 写完整。特别是【Mark】和【Wardrobe 标志配饰】——
        这两项是模型唯一能牢牢抓住的"钩子"。没有钩子的角色一定会漂。

第 2 步  出三视图定妆照
        用下面的 CHARACTER_SHEET 提示词，16:9 / 2K，一次出 4 张，人工挑 1 张。
        ★ 这一步值得花钱用最贵的档位（Nano Banana Pro 4K），一次投入全片受益。

第 3 步  拆分定妆照
        裁成 front.png / three_quarter.png / profile.png 三张独立图。
        多参考图输入时，分开的单视角图比一整张拼图效果更稳。

第 4 步  出表情/姿态补充图
        以定妆照为参考，生成 2-3 张不同表情（微笑 / 落泪 / 惊讶）。
        三视图 + 表情图 = 该角色的"资产包"，此后每张分镜从包里挑 2-3 张当参考。

第 5 步  ★ 风格锁校准
        用同一段 STYLE LOCK 生成 3 张完全不同的场景（室内 / 室外 / 夜景），
        确认画风一致。不一致 = STYLE LOCK 写得不够具体，回第 2 步补细节。

第 6 步  批量出分镜
        每张 = 角色资产包(2-3张) + IDENTITY_LOCK + 场景描述 + STYLE_LOCK

第 7 步  ★ 滚动锚定（关键技巧）
        每出一张满意的分镜，就把它加入参考图池，替换掉最早的一张。
        这样风格沿着片子自然演进而不是突变。
```

### 定妆照提示词模板

```
A character reference sheet of a single character, on a plain neutral grey background.
The character: 【把 CHARACTER LOCK 的 Identity/Face/Hair/Mark/Wardrobe 展开成一段】
Show three views side by side: front view, three-quarter view, and side profile.
Same height, same lighting, neutral expression, arms relaxed.
【STYLE LOCK】
```

## 五、知识线不要用扩散模型画图

**扩散模型画中文字永远是残的。** 知识线需要的是**排版精确、文字锐利**的信息卡片，正确做法是 **HTML/CSS 排版 + 无头浏览器截图**：

- 文字 100% 锐利可控、零 token 成本、完全确定性、可重复
- 三种尺寸一次覆盖：`1080×1440`（小红书 3:4）、`2100×900`（公众号头图）、`1080×1080`（1:1 分享卡）
- 可参考开源实现：`op7418/guizang-social-card-skill`（28 个版式 + 10 套主题 + Playwright 校验）

**卡片自动预检的 6 条硬规则**（值得抄进 G2 自检）：
1. **溢出**：任何内容不得越出卡片边界
2. **字号封顶**：字重/字号组合必须匹配预设，防止乱调
3. **页脚碰撞**：正文不得压到页脚
4. **四带密度**：画布横切成 4 个带，每带必须有内容或**有意留白**（防头重脚轻）
5. **截图 frame 溢出**
6. **风格身份校验**：极简风字重 ≥700 触发警告

**一条设计铁律**：**只允许选预设主题，禁止自定义 hex 色值。** 这是防止 AI 审美崩坏最有效的一招。

## 六、分镜提示词的拼装规则（写进 02_分镜脚本.md）

每一镜的生图提示词 = 三段拼接，顺序不能变：

```
[IDENTITY_LOCK]  ← 从角色资产库原样复制，声明"和参考图是同一个人"
[SCENE]          ← 本镜独有：场景 + 景别 + 机位 + 光线 + 动作
[STYLE_LOCK]     ← 原样复制，一个字不改
```

**IDENTITY_LOCK 写法**（放在场景之前，不是之后）：
```
The SAME woman as in the reference sheet: oval face, single eyelids,
shoulder-length straight black hair with blunt bangs, small mole under her right eye,
faded denim jacket, red woven bracelet on left wrist.
Keep her facial features, hairstyle and outfit completely unchanged.
```

**SCENE 必须包含的 5 要素**：场景 + 景别（wide/medium/close-up）+ 机位（low angle/from behind/eye level）+ 光线 + 动作。

## 七、G2 生图自检清单

- [ ] 角色资产库里有该角色的定妆照（三视图 + 至少 1 张表情图）
- [ ] 全片使用同一段 STYLE LOCK，逐字比对无差异
- [ ] 每镜提示词按 `IDENTITY_LOCK + SCENE + STYLE_LOCK` 顺序拼装
- [ ] 提示词中**没有任何代词**（her / it / the character）
- [ ] 反复出现的物件已登记为 clue，且各镜描述完全一致
- [ ] 画幅正确：视频 9:16 / 小红书 3:4 / 公众号头图 21:9
- [ ] 知识线的信息卡片走 HTML 排版，**没有让扩散模型写中文字**
- [ ] 未使用真人肖像、未模仿在世艺术家署名风格（账号红线第 5 条）
