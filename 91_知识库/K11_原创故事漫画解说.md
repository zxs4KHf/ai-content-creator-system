# K11 · 原创故事漫画解说

> 目标是把原创故事做成“旁白驱动、画格承载证据、节拍清楚”的竖屏漫画解说。外部漫画/解说视频只用于学习抽象功能，不下载、不截帧、不复述原文、不改名换皮；《故事会》《意林》及网文故事不作为改编素材。

## 一、它不等于图片轮播

漫画解说同时有三条时间线：

1. **因果线**：观众此刻知道什么，新信息怎样改变前一个判断；
2. **画格线**：每次换画格必须对应新的信息状态、视线目标或关系变化；
3. **声音线**：旁白负责推进，关键对白负责角色，音效只标记动作/空间，不把全片铺满。

如果只是每 5 秒换一张图、持续 Ken Burns、字幕逐句出现，它仍是插画轮播，不是漫画解说。

## 二、推荐的 8 节拍

| 节拍 | 功能 | 画格任务 |
|---|---|---|
| B1 冷开 | 先给反常结果/危险/选择 | 0–3 秒内出现最强因果画面，不先讲世界观 |
| B2 身份 | 谁在什么规则里生活 | 一张建立人物与环境关系的全格 |
| B3 缺口 | 什么东西不对劲 | 细节格或局部特写，让观众先看到证据 |
| B4 进入 | 新人物/事件打破平衡 | 方向明确的进入画格，不用随机转场代替动作 |
| B5 加压 | 连续两次尝试或信息升级 | 大格 + 小格，不能两格表达同一状态 |
| B6 关键动作 | 关系/规则真正发生变化 | 接触、交付、删除、打开等动作必须有可读状态 |
| B7 反转 | 早先信息被重新解释 | 先停半拍，再揭示；禁止边说反转边提前展示结果 |
| B8 余味 | 用选择的后果收束 | 留一个稳定末格，不再追加第二个主题 |

## 三、画格语法

- **常规大格约 70%**：承担人物、空间和主要动作，是全片基线。
- **细节格约 20%**：只放手、物件、文字痕迹、眼神或结果证据；必须回答“为什么此刻要看它”。
- **冲击格不超过 10%**：反转、关键接触或结局才可占满画面/快速推近；一条 60–90 秒视频通常 2–3 次。
- 同一节拍内可以先展示全格，再切细节；不要同时摆三个等权画格让手机观众寻找重点。
- 漫画框、速度线、拟声字、白闪和震动都是叙事标点，不是常驻滤镜。
- 字幕承担可读口播；画内字只放关键词、角色短句或可验证信息，不能把整段旁白塞进气泡。

## 四、运动与转场

1. **画格内部**遵守 K8：主体、环境、摄影机最多一个强通道；静态图优先轻推、平移或停格。
2. **画格之间**只在语义边界切换。普通信息硬切/短溶解；进入/离开可定向擦入；时间跃迁可用明确的页翻/色调变化。
3. 反转前允许 150–350ms 的视觉稳定，给观众形成旧判断；反转后再切证据格。
4. 同一段旁白的镜头变化来自信息状态，不按固定 2 秒“防无聊”乱切。
5. 每次运动在末段稳定，让字幕和关键物件至少有一段可读时间。

## 五、声音

- 旁白是第一优先级；采用 K10/T9/T12 的自然度、停顿、情绪弧、英文和稳定性门。
- 角色对白只在它比旁白更能暴露选择时保留；同一人不要在旁白腔和对白腔之间突然换声线。
- 音效分三类：空间（雨/门/房间底噪）、动作（翻页/递物/落笔）、转折（极短静音或单次冲击）。每镜最多一个主要音效。
- BGM 不代替情绪结构；没有明确授权来源就保持无 BGM 基线。

## 六、当前确定性实现

`build_video.py --frame-style comic` 在不新增素材的情况下生成影子版：

- 深色虚化底板 + 严格 9:16、完整保留源画面的白边硬框主画格；
- 保留现有真实旁白时间轴、K8 运镜和转场；
- 底部保留平台交互安全留白，字幕仍处于主画格安全区，顶部保留 AI 标识；
- 不覆盖 `full` 全幅基线，输出必须使用独立文件名。

它解决的是“画格化呈现和路线验证”，不是自动创造新动作或多格构图。只有当某个节拍确实需要细节证据时，才新增一张局部图或显式拆镜；不能为了像漫画而把同一张图重复裁成多个无意义格子。

## 七、G3 前 QA

- [ ] 0–3 秒是否先出现反常结果/选择，而不是背景说明
- [ ] 每次换格是否能指出新增信息，删掉后是否会损失理解
- [ ] 全格/细节格/冲击格是否有明显主次，不让视线迷路
- [ ] 关键动作是否有前态、接触/变化、后态，或明确使用静态降级
- [ ] 字幕在 6 英寸屏幕可读，没有压住脸、手和关键物件
- [ ] 反转没有被画面提前泄露，结尾有稳定余味
- [ ] 画格、转场、音效没有每镜重复同一模板
- [ ] 0/25/50/75/100% 与所有接触/遮挡帧通过
- [ ] 内容为原创/公版/获授权，外部参考没有进入画面、台词、故事链或声音
