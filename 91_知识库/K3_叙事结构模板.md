# K3 · 叙事结构模板

> 写 `00_选题方案.md` 的"结构"一栏时，必须从本文件选一个模板并注明编号。**不要自由发挥结构**——结构是被验证过的，创意应该花在内容上。

---

## 一、故事线结构

### S-1 三幕反转（60 秒，故事线默认）

```
0-3s    反常结果开场（钩子 B4/B7）
3-15s   背景铺垫：交代人物与处境，不解释动机
15-40s  冲突升级：至少一次加码，让观众以为自己猜到了
40-55s  反转揭真相：推翻观众的猜测
55-60s  金句收尾（≤15 字），不解释
```
例：女儿觉得妈妈偏心弟弟（铺垫）→ 翻出妈妈日记发现攒了多年嫁妆钱（反转）→ "有些爱，说不出口"。

**分镜对应**：8-12 镜。铺垫 3-4 镜，冲突 3-4 镜，反转 2 镜，收尾 1 镜（定格 + 金句大字）。

---

### S-2 倒叙悬念（60 秒）

```
0-3s    直给最高潮画面（最美/最痛的那一张插画）
3-10s   "这一切要从……说起"
10-45s  时间线顺序推进
45-60s  回到开头画面，首尾呼应 + 金句
```
例：开头"他站上颁奖台落泪" → 回溯"三年前还是外卖骑手" → 收尾"外卖箱里装的不只是餐"。

**分镜对应**：镜 1 与最后一镜**必须是同一张图或同一构图的两个时刻**——这是"呼应"的视觉载体，也顺便省一张生图。

---

### S-3 静物凝视（90 秒，适合我们的插画形态）

一个物件贯穿全片，人只在物件的反应里出现。慢节奏、留白多、金句重。

```
0-5s    一个物件的特写，无人（钩子 B5 视觉冲击）
5-30s   物件的第一段时间：它曾经属于谁
30-55s  时间跳跃：物件还在，人变了
55-80s  物件的当下：它现在的处境
80-90s  金句：把物件的处境翻译成一句关于人的话
```
**为什么适合我们**：物件比人脸更容易保持生图一致性（见 K5 的 Clue Tracking），且天然契合"温暖、克制、留白"的人设。

---

### S-4 八阶段故事设计（长内容/公众号/B站正片）

| 阶段 | 内容 |
|---|---|
| 1 目标受众 | 意味深长的情绪感染 |
| 2 主题/背景 | 用社会语境、人物、核心价值观建立**平衡** |
| 3 激励事件 | **失衡**——打破主角的平衡 |
| 4 欲望对象 | 未被满足的需求，驱动人物目标 |
| 5 第一次行动 | 初步策略，获得正反馈 |
| 6 第一次反馈 | **悖反期望**——出现负面结果 |
| 7 危机/顿悟 | 人物获得认知，准备赌注更高的第二次行动 |
| 8 高潮解决 | **达成**——主角得到或失去欲望对象 |

故事的定义：「一系列由冲突驱动的动态递进的事件，在人物的生活中引发了意义重大的改变。」

---

### 故事线的节奏工程 [实测]

| 手法 | 数据 |
|---|---|
| 快切 | 头部剧情号可做到 88 秒内 66 次切换（平均 **1.3 秒/切**） |
| 音乐切换 | 2 分钟视频内切换 **2-3 次** |
| 人设固定 | 造型与外观固定，便于识别（对我们=角色资产库锁死） |
| 旁白推进 | 后期配音推进剧情，减少出镜台词（正是我们的形态） |

**我们的取舍**：插画视频做不到 1.3 秒/切（生图成本），但**可以用 Ken Burns 运镜 + 转场制造"切"的感觉**。目标：单张图停留 **3-6 秒**，超过 8 秒必然掉完播。8-12 镜是 60 秒片的合理密度。

## 二、知识线结构

### K-1 倒金字塔（先结论后过程，知识线默认）

```
0-3s    直给结论（钩子 A1/A6/A10）
3-8s    一句话方法论
8-50s   分点展开演示
50-60s  重复结论 + 行动号召
```

### K-2 痛点开场

```
0-5s    强痛点提问（钩子 A2/B1）
5-10s   共情放大："我也这样，直到……"
10-45s  分步给方案
45-60s  总结升华
```

### K-3 清单体（**小红书知识线一律用这个**）

```
0-3s    数字化标题预告："5 个……"
3-8s    清单概览（字幕列表增强停留）
8-50s   逐条展开，每条 10-15 秒
50-60s  回顾 + 引导收藏
```
**为什么**：清单体触发"工具属性"信号，是小红书收藏率最高的结构（见 K2 第二节）。

### K-4 对比体

```
0-5s    并列展示引好奇
5-15s   错误做法 + 后果
15-40s  正确做法 + 原理
40-55s  效果对比
55-60s  总结提醒
```

### 知识线的埋点法则 [实测]

一条内容要埋齐 **槽点、痛点、尿点、笑点、价值点**。至少三个。

## 三、双线交叉结构（本账号最大差异化）

### X-1 作品 + 幕后（B站/公众号专用）

```
正片（60-70%）：故事或教程主体，与其他平台一致
幕后（30-40%）：这条内容是怎么用 AI 做出来的
  - 我给 AI 的原始想法是什么
  - 它第一版写成了什么样（可以展示翻车的版本）
  - 我改了哪里、为什么
  - 生图翻了几次，附对比图
```
**为什么有效**：故事引流，幕后转粉。别的账号要么只讲工具、要么只发作品，我们两头都占。**幕后部分不要美化过程**——暴露失败是人设的一部分。

### X-2 元内容（K1 类选题）

把"搭这条流水线本身"作为知识线选题。每跑通一个环节就是一条内容。

## 四、选题是否值得做——5 项自检

1. **需求真实性**：评论区或搜索框里有没有人主动问？
2. **竞争度**：同类供给是否已饱和？
3. **可延展性**：能否延伸出 5 期以上不重复的系列？
4. **匹配度**：贴合账号人设吗？能承接转化吗？
5. **时效性**：热点通常前 3 天效果最好，跟不上就放弃。

**任何一项答"否"，在选题方案里必须写明并给出补偿方案，否则 G1 直接淘汰。**
