# K12 · 稳定角色动画与资产管线

> 适用于长期角色、2D 绑定、3D 动画、服饰/年龄变体和生成式英雄镜。详细证据见 `93_运行记录/调研_角色动画服饰年龄变化复刻路线_2026-07-29.md`。

## 一、生产原则

1. **先资产，后镜头。** 长期角色的身份、骨骼、表情、服装和年龄版本必须可复用、可编辑、可回归测试；不靠每集重新提示生成维持一致性。
2. **先确定性全片，后英雄镜升级。** 静帧/2D/3D 的可复现基线先完整成立，生成式 I2V/V2V 默认只替换 1–3 镜。
3. **动作、表情、口型、摄影机分轨。** 一个“让角色动起来”的字段不足以进入生产。
4. **动作捕捉只是底片。** 双脚、重心、手指、道具接触、眼神、表情和次级运动必须清理。
5. **外部游戏角色只研究方法。** 没有 IP、模型、纹理、动作、声音和音乐的权利闭环，不进入变现成片。

## 二、角色资产合同

每个长期角色必须有以下标识：

| 字段 | 含义 |
|---|---|
| `CHARACTER_ID` | 跨内容不变的角色身份 |
| `ASSET_VERSION` | 网格、绑定或 2D 立绘资产版本 |
| `AGE_VARIANT` | child / youth / adult / elder 等独立版本 |
| `OUTFIT_ID` | 服装网格/立绘、材质、权重和许可版本 |
| `FACE_SET` | 表情与口型集合版本 |
| `RIG_VERSION` | 骨骼、约束、控制器版本 |
| `RIGHTS_RECORD` | 代码、模型、纹理、动作、参考、输入和输出权利 |

缺任何一项时只允许做探索样片，不得称为“稳定角色管线”。

## 三、服饰与年龄

- 服装必须记录网格/层级、材质、权重、遮挡、物理策略和 8 姿势穿插测试。
- 日常镜优先骨骼/简化碰撞；布料、长发和饰品物理只给英雄镜。
- 儿童版不得由成人模型等比缩小；头身、四肢、肩胯、手脚、动作节奏和服装需独立验收。
- 年龄或服装变化必须由剧情触发，镜头前后写清版本切换，不能由生成漂移“顺便变化”。

## 四、逐镜动画卡

每镜至少填写：

- `INTENT`：观众认知/情绪变化；
- `F0 / K / F1`：起始、必要中间姿态、终止状态；
- `BODY`：触发 → 感知 → 预备 → 主动作 → 落稳；
- `FACE/EYES`：情绪、眼神对象、眨眼、表情峰值与落稳；
- `LIPSYNC`：声音文件/hash、口型工具、人工修正点；
- `CAMERA`：起点、路径、目标、速度、停点；
- `CONTACTS`：手/脚/道具/地面接触；
- `SECONDARY`：头发、衣摆、饰品、环境；
- `METHOD`：静帧 / 2D rig / 3D keyframe / mocap / I2V / V2V；
- `FALLBACK`：失败时可无损替换的确定性镜头；
- `ACCEPTANCE`：一票否决条件。

详细填写使用 `90_模板库/T14_角色动画样片实验卡.md`。

## 五、动作清理顺序

`根运动/比例 → 双脚锁地 → 髋和脊柱重心 → 手与道具接触 → 头眼朝向 → 手指 → 表情/口型 → 头发衣摆饰品 → 曲线减速/落稳`

顺序不得反过来；先做头发和表情再改根运动会重复返工。

## 六、生成式视频预算

- 当前 8GB 本机可研究 FramePack 或 LTX 2B 低显存路线，但不能从“能启动”推导到“能批量生产”。
- 官方要求超过本机的模型不做本地默认：HunyuanVideo-1.5 官方最低 14GB，Wan2.2 720p TI2V 官方至少 24GB。
- 同配置连续失败两次，必须改变一个可归因变量或回退；禁止继续盲抽。
- 生成镜必须检查 0/25/50/75/100% 与所有接触/遮挡帧；任一身份、服装、手部、道具、背景或文字漂移即拒收。

## 七、G1/G2/G3 嵌入

### G1

- `REUSE_POTENTIAL`：角色、场景、道具能否跨集复用；
- `ASSET_TIER`：静帧 / 2D / 3D / 随机生成；
- `HERO_MOTION`：最多 1–3 个必须运动的镜头；
- 回退后题目是否仍成立。

### G2

- 冻结角色/年龄/服装版本；
- 冻结真实旁白，再做口型；
- 建连续性账本和逐镜动画卡；
- 先完成低清 animatic；
- 明确新增资产、人时、显存和回退。

### G3

- 静音看得懂动作，闭眼听得懂情绪；
- 角色身份、服装、年龄、道具、眼线和轴线连续；
- 动态镜明显优于确定性基线；
- 资产权利、AI 标识和声音授权记录完整。

## 八、当前项目路由

1. 故事会经典故事：漫画层级/2D 为默认，不等待 3D；
2. 原创长期角色：内容方向有真实数据后，再建 Blender 母资产；
3. 20 秒角色对话样片先于完整 60–90 秒 3D 成片；
4. 若 20 秒样片的人时、口型或接触质量不合格，退回 2D 绑定；
5. 外部优质二创只沉淀抽象资产和表演方法，不复用其角色、声音、剧情或镜头链。
