## 一、抖音

**算法**：官方已上线披露站 `trust.douyin.com`，公式表述为「综合预测用户行为概率 × 行为价值权重 = 视频推荐优先级」[官方]。具体权重表官方未公开表格化数据。

| 项 | 值 | 标注 |
|---|---|---|
| 指标优先级 | 完播率 > 点赞率 > 评论率 > 转发率 > 关注转化率 | [民间] |
| 完播率参考 | 15 秒内 ≥45% 优质 / 30-45% 及格；30-60 秒 ≥30% 合格、40%+ 爆款；1-3 分钟 ≥20% | [存疑] 另有来源称整体均值 15-20% |
| 时长甜区 | 故事线 30-60 秒；知识线 30-60 秒；系列剧情 1-2 分钟 | [民间] |
| 1 分钟权限 | 2019-04-25 官方全面开放，无粉丝门槛 | [官方] |
| 3/5/15/30 分钟权限门槛 | **未查到官方数字，需到创作者后台实测** | [未核实] |
| 文案上限 | ~500 字符；标题实操 15-20 字 | [存疑] |
| 话题标签 | **官方上限未查到**；经验值 3-6 个精准标签 | [未核实] |
| 视频规格 | 1080×1920，H.264，MP4，30fps，≥8Mbps，≤4GB | [实测] |
| 封面安全区 | 底部约 25% 被 UI 遮挡；封面建议单独出 1080×1440 (3:4) | [存疑] 两说冲突 |
| 发布时间 | 12-14 点（剧情/知识）/ 18-22 点（全天最高但竞争最烈）/ 22-24 点（情感） | [民间] |

**限流真相**[官方表态]：抖音官方（李亮）明确回应，谈钱、谈死等词**不会**限流。真正触发限流的是：广告极限词、无资质讲金融、直播怂恿酗酒等。**不要为了"避词"把文案写得畸形。**

**违规红线（有法条）**：极限词（广告法第 9 条，罚则第 57 条，20 万-100 万）、医疗暗示（第 17 条）、价格欺诈（反不正当竞争法第 8 条）、AI 内容未标注（见 K6）。

## 二、小红书

| 项 | 值 | 标注 |
|---|---|---|
| **标题上限** | **20 字，超出无法输入** | [实测] |
| 正文 | 历史约 1000 字；2025-07 长文功能上线后可超千字，新上限未公开 | [实测] |
| 图片数量 | 9 张（多数来源）vs 18 张（称 2024 更新） | [存疑] **按 9 张设计，超出部分做第二篇** |
| 建议张数 | 6-9 张 | [民间] |
| **首选比例** | **3:4，1080×1440px** | [实测] 4 源一致 |
| 备选比例 | 1:1 (1080×1080) / 4:3 (1080×810) | [民间] |
| 视频笔记 | ≤15 分钟 | [实测] |
| **标签数量** | 上限 ≤10；**建议 3-5 个**（精准垂类 1-2 + 热门 2-3 + 泛流量 1） | [实测] 2 源一致 |
| 标签位置 | 放**正文内**（开头/中间/结尾各布一个） | [实测] |
| 审核时长 | 机审几分钟；人审数小时-24h，敏感/高峰可达 48h | [存疑] |
| 笔记生命周期 | 普通笔记 7 天后明显衰减；靠搜索的优质笔记可延续数月 | [民间] |
| 发布时间 | 工作日 19:00-22:00；周末 14:00-17:00 | [存疑] |

**CES 互动分公式**：`点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8` [民间][存疑]——4 个来源引用一致，但**查无官方出处**。另有版本为 关注10/转发8/评论6/收藏4/点赞2。**当作方向性参考，不要当作精确公式优化。**

**为什么收藏率是核心**：收藏 = 内容"可复用/工具属性"的信号，代表长期留存价值而非即时情绪。攻略、清单、教程类尤其吃这个。→ **知识线在小红书一律用清单体结构**（见 K3）。

**封面设计**（三来源不统一，均属民间共识）：
- 主标题 3-7 字，字号 80-120px；副标题 40-60px
- 文字总量 ≤10-15 字
- 安全区：上下各留 10%，或底部留 15%
- 主体占比 ≥60%，高饱和色块 + 强对比文字背景

**SEO 关键词布局**（按权重降序，很重要）：
`标题 → 正文开头 100 字 → 正文中段 → 结尾 → 图片内文字 → 话题标签 → 评论区 → 昵称简介 → 合集名`
密度建议 2-8%。

**违规**：《交易导流商业秩序治理规则公告》（2024-11）[官方] 禁止微信号/电话/二维码站外导流。蒲公英积分制：2 分提醒 → 4 分限自然流量 7 天 → 6 分限搜索 7 天 → 8 分限流 28 天 → 10 分永久封禁；连续 28 天无违规清零。

## 三、B站

| 项 | 值 | 标注 |
|---|---|---|
| **时长甜区** | 全站 **5-10 分钟留存最高（31.5%）**；知识科普 8-15 分钟 | [实测] |
| 留存基准 | 教育科普类平均留存 **42.1%**；Vlog 类 21.5% | [实测] |
| 开头黄金 1 分钟 | 开头 1 分钟留存 >65% 的视频，整体观看时长平均高 **58%**；**前 15 秒讲清价值点可使 1 分钟留存 +18%** | [实测] |
| 播放分钟数 | 2023-07 官方把外显"播放量"改为"播放分钟数"（2 倍速看 10 分钟只算 5 分钟）；官方证实该指标一直是热门推荐与创作激励的参考因素 | [官方] |
| 封面 | **1146×717px**，≤5MB，JPG/PNG | [实测] 多源一致 |
| 标题上限 | 常引用 80 字 | [存疑] |
| 简介上限 | **未查到** | [未核实] |
| TAG 上限 | 多个教程指向 10 个 | [存疑] |
| 章节功能 | 官方"分段章节"（高能进度条），稿件管理页手动打点 | 功能确认，细则存疑 |
| 发布时间 | 工作日 20:00-21:00 最佳 | [存疑] |

**为什么投币权重高**[官方机制]：经验值体系中观看/分享记 5 点，**投币记 10 点**；投币消耗的是需要等级成长换取的稀缺代币，属高成本操作，且收益 10% 返给 UP 主。
→ **结尾不要泛泛喊"三连"，要给出具体的投币理由**（"如果这套流程帮你省了两小时，投个币让我知道值得继续做"）。

**官方算法口径**[官方]：综合考虑播放量、播放分钟数、互动氛围（点赞/投币/收藏等消费情况）。

## 四、微信公众号

| 项 | 值 | 标注 |
|---|---|---|
| **标题上限** | **64 字** | [官方] |
| **摘要上限** | **120 字** | [官方] |
| **正文上限** | **5 万字** | [官方] |
| 作者名 | 8 字 | [官方] |
| 发表后修改 | 标题 ≤3 字，正文 ≤120 字，图片 ≤3 张，视频 ≤1 个；**每篇仅限改一次** | [官方] |
| 群发次数 | 订阅号每天 1 次；服务号每月 4 次；每次最多 8 篇 | [官方] |
| 原创门槛 | 正文 ≥300 字才启动 AI 原创比对 | [存疑] |
| 打开率基准 | 单篇中位数 **1.9%**，头条最高 4.3%，第 8 条低至 0.4% | [实测] |
| 流量来源 | **71% 阅读来自消息列表，16.1% 来自好友分享** | [实测] |
| 常读用户 | 均值约 11%；常读占比 >60% 的账号打开率可达 8.2% | [实测] |
| 发布时间 | 头部集中 21:00-22:00，其次 18:00-19:00 | [存疑] |

**排版规范**[民间，非微信强制]：正文 15-16px（默认 15px）；行距日常 1.75-1.8 倍、长文 1.8-2.0 倍；段间距约 5px；正文色 `#3f3f3f` 或 `#444444`（**不要纯黑**）；全文配色 ≤3 种。

**诱导处罚阶梯**[官方]：文章禁转发 → 删文 → 删粉 → 封禁部分能力 → 封号。三类诱导：强制型（不转不能用）、利诱型（转发抽奖/助力）、话术型（"转发一生平安"）。

> **推论**：71% 阅读来自消息列表 ⇒ **标题就是全部**。公众号标题不要复用小红书标题（20 字），要用满 30-50 字把信息量给足。

## 五、视频号

**最强官方数据点**：张小龙 2021 微信公开课明确 `关注 : 朋友 : 推荐` 的播放量消耗比目标为 **1:2:10**[官方演讲实录]，后台实测接近 1:2:9。

| 项 | 值 | 标注 |
|---|---|---|
| **核心机制差异** | 好友点赞会让内容**直接进入其"朋友"栏曝光，无需算法参与**——这是抖音完全没有的分发路径 | 机制性 |
| 时长（手机） | 3 秒 - 60 分钟 | [官方] |
| 时长（电脑） | 3 秒 - 8 小时 | [官方] |
| 宽高比 | 0.33-3.0，推荐 16:9 或 9:16 | [官方] |
| 文件大小 | ≤2GB；建议 1080p+ | [官方] |
| 不支持 | GIF、HDR、电脑 Chrome 上传 h265 | [官方] |
| 文案 | ≤1 分钟视频：≤1000 字；>1 分钟：≤100 字；**推荐 20 字内，全屏最多显示 2 行** | [存疑] |
| 话题标签 | 一说上限 5 个，一说无上限 | [存疑] 按 5 个设计 |
| 指标权重 | 完播率（占比最大，20 秒视频完播 <10% 极难获推荐）> 分享率 > 点赞率 > 评论率 | [存疑] |

**原创声明 9 类禁止**[官方]：加字幕的伪原创、未授权引用、单纯转发新闻/政府文件、营销宣传、非独家授权、未获独家授权的再创作、**时长不足 5 秒**、违法违规、其他侵权。

> **推论**：视频号要专门设计一个"值得好友点赞"的点——因为好友点赞能绕过算法直接曝光。这个点通常是：一句能代表转发者立场的金句，或一个足够美的画面。
