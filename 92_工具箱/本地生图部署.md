# 本地生图部署（可选）

> **先说结论：起号期不要装。** 云端 API 12 张分镜约 ¥3-11，一个月 20 条也就百来块。
> 本地方案只在两种情况下值得：出图量非常大（月产 100+ 条），或者需要完全离线。
>
> 本文件是"将来要用时的备查"，不是现在要做的事。

---

## 一、选型结论：按精确组件链选择

当前高质量候选仍是 **Qwen-Image-Edit-2511 官方 BF16 权重链**；官方代码、权重和主要 Qwen 组件均标 Apache-2.0。但它不是“所有本地方案里唯一干净的”，第三方量化、LoRA、ComfyUI 整合包和参考图权利仍要逐项核验。

官方改进清单包含 *"mitigate image drift, improved character consistency"* —— **正是我们的痛点**。

### ⚠️ 许可与维护不是一回事

完整分层证据和当前决策见 `91_知识库/K5_生图一致性手册.md` 与
`93_运行记录/调研_生图一致性模型许可_2026-07-28.md`。部署时至少分别核对代码、适配器/模型权重、底模、依赖权重、输出条款和输入素材权利。

- 通用 IP-Adapter（非 FaceID）不强制依赖 InsightFace，不能被 FaceID 路线的限制一刀切；只有完整组件链放行后才评估商业生产。
- InstantID、IP-Adapter-FaceID 和标准 PuLID 免费链的 checkpoint / InsightFace 权利尚未闭环，当前不用于商业成片；原因不是“提交较旧”。
- `ComfyUI_IPAdapter_plus` 是 maintenance-only，不等于已弃用，也不等于上游 IP-Adapter 自动失效。
- FLUX 是模型家族，不是一种许可。FLUX.2 `[dev]` 免费权重限制商业/生产运行，但输出条款需另读；`[klein]` 4B 等准确型号另有许可证，不能概括成“Flux 全禁商用”。
- 本机 8GB 可以研究 FLUX.2 `[klein]` 4B 等明确放行的轻量候选；质量、角色一致性和完整依赖仍需实测/复审。

## 二、显存分档

GGUF 文件大小是最可靠的显存下限参考：

| 量化 | 大小 | 建议显卡 |
|---|---|---|
| Q2_K | 7.15 GB | 8GB（勉强，画质有损） |
| Q3_K_M | 9.76 GB | 12GB |
| **Q4_K_M** | **13.1 GB** | **16GB ← 甜点** |
| Q5_K_M | 14.9 GB | 16GB 紧 |
| Q6_K | 16.8 GB | 24GB |
| Q8_0 | 21.8 GB | 24GB |
| fp8_e4m3fn（非 GGUF） | 20.4 GB | 24GB |

⚠️ 另需文本编码器 `qwen_2.5_vl_7b_fp8_scaled.safetensors`（约 8GB），
但 ComfyUI 编码完会卸载，峰值 ≈ 上表数字 + VAE + latent。

## 三、安装（ComfyUI）

```bash
# 1) GGUF 加载器（低显存必装）
cd ComfyUI/custom_nodes
git clone https://github.com/city96/ComfyUI-GGUF
pip install -r ComfyUI-GGUF/requirements.txt

# 2) 模型下载
pip install -U "huggingface_hub[cli]"

# --- 24GB 显存：fp8 路线 ---
hf download Comfy-Org/Qwen-Image-Edit_ComfyUI \
  split_files/diffusion_models/qwen_image_edit_2509_fp8_e4m3fn.safetensors \
  --local-dir ComfyUI/models/

# --- 16GB 及以下：GGUF 路线（放 unet 目录）---
hf download QuantStack/Qwen-Image-Edit-2509-GGUF \
  Qwen-Image-Edit-2509-Q4_K_M.gguf --local-dir ComfyUI/models/unet/

# 3) 公共依赖
hf download Comfy-Org/Qwen-Image_ComfyUI \
  split_files/text_encoders/qwen_2.5_vl_7b_fp8_scaled.safetensors \
  split_files/vae/qwen_image_vae.safetensors --local-dir ComfyUI/models/

# 4) 4 步加速 LoRA（20 步 → 4 步）
hf download lightx2v/Qwen-Image-Lightning \
  Qwen-Image-Lightning-4steps-V1.0.safetensors --local-dir ComfyUI/models/loras/

# 5) 官方工作流模板
curl -O https://raw.githubusercontent.com/Comfy-Org/workflow_templates/refs/heads/main/templates/image_qwen_image_edit_2509.json
```

## 四、工作流关键参数

**节点链**：
`UNETLoader`（或 GGUF 版 `Unet Loader (GGUF)`）→ `LoraLoaderModelOnly`（Lightning）
→ `ModelSamplingAuraFlow` → **`TextEncodeQwenImageEditPlus`** → `KSampler` → `VAEDecode`

**`TextEncodeQwenImageEditPlus` 就是多参考图入口**——把多个 `LoadImage` 接到它的 image1/image2/image3。
这对应我们的"角色资产包"（定妆照三视图 + 表情图）。

**KSampler 参数**：
- Lightning 模式：`steps=4, cfg=1.0, euler, simple, shift=1`
- 关掉 Lightning：`steps=20, cfg=4.0`

## 五、diffusers 直跑（不用 ComfyUI）

```python
import torch
from diffusers import DiffusionPipeline
from diffusers.utils import load_image

pipe = DiffusionPipeline.from_pretrained(
    "Qwen/Qwen-Image-Edit-2511", dtype=torch.bfloat16, device_map="cuda")

img = pipe(
    image=[load_image("char_sheet.png"), load_image("scene_ref.png")],   # 多图输入
    prompt=("The woman from image 1, keeping her face, hairstyle and denim jacket "
            "completely unchanged, now standing on the snowy train platform from image 2, "
            "wide shot, dusk, cold blue light."),
    num_inference_steps=40,
    guidance_scale=1.0,
    true_cfg_scale=4.0,      # 官方推荐值
).images[0]
img.save("shot.png")
```

## 六、LoRA 训练（角色一致性的天花板）

只有当某个角色要跨很多条内容反复出现时才值得。

**工具：ai-toolkit（ostris）**，支持 Qwen-Image / Qwen-Image-Edit / FLUX / SDXL / Wan 等。

```bash
git clone https://github.com/ostris/ai-toolkit && cd ai-toolkit
pip install -r requirements.txt

cp config/examples/train_lora_flux_24gb.yaml config/my_character.yml
# 编辑：改 dataset 路径、trigger word、steps
python run.py config/my_character.yml

# 或用 Web UI
cd ui && npm run build_and_start     # http://localhost:8675
```

**数据集规模**：15-30 张不同角度和表情的精选参考图。

⚠️ 官方 README 只给了 24GB 的示例配置，**没有明确说明 16GB / 12GB 的最低要求**。
社区有低显存量化训练方案，但未经核实。

## 七、提示词差异（对比云端）

本地 SD/Qwen 系**有真正的负面提示词框**，而 Gemini 没有：

```
【负面提示词】（本地方案专用）
extra fingers, deformed hands, multiple people, changed hairstyle,
different clothing, photorealistic skin, harsh contrast, text overlays,
borders, watermark, signature, lowres, jpeg artifacts
```

云端 Gemini 要把负面写成正向陈述：`her hands are relaxed and clearly visible with five fingers`
优于 `no extra fingers`。

其余（角色锁、风格锁、三段拼装、滚动锚定）两边完全一致，见 `91_知识库/K5_生图一致性手册.md`。
