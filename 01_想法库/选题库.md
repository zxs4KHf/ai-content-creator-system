# 选题库

> AI 整理收集箱后写入这里。作业规范见 `91_知识库/K7_选题雷达源.md`。
>
> **四维打分**（各 1-5 分，满分 20）：
> - **契合**：与账号定位/内容线的契合度（5 = 双线交叉，只有我们能做）
> - **需求**：目标受众的共鸣或实用需求强度（5 = 评论区有人主动问）
> - **成本**：制作成本，**分越高成本越低**（5 = 当天能出，≤2h + ≤6 张图）
> - **差异**：同类供给的饱和度，**分越高越蓝海**（5 = 全网几乎没有）
>
> **打分纪律**：同一批必须有高有低，禁止全给 4 分；每个维度必须附一句话理由。
> **门槛**：总分 ≥15 进 G1 候选；12-14 进观察区；<12 淘汰并写原因。
>
> **状态**：候选 → G1通过 → 制作中 → 待发布 → 已发布 / 淘汰
>
> **矩阵实验**：进入实验的选题还必须在 `矩阵实验池.md` 记录 `experiment_id / hypothesis_id / 栏目或账号 / 唯一主变量 / 固定项 / 观察窗`。本表负责“值不值得做”，矩阵池负责“为什么这样做、如何归因”。
>

> 种子选题的分数是估算的，**不要当作已验证的判断**。
