# 角色资产库

> **这是本系统最有价值的资产之一。** 角色跨图不一致是插画故事视频的头号杀手——
> 一条 12 镜的片子，只要有 2 镜的人脸不像，观众就出戏，前面所有努力归零。

## 怎么用

**新角色**：
1. 用 `90_模板库/T5_角色卡模板.md` 建卡，编号 `C001`、`C002`…
2. 跑 `92_工具箱/gen_images.py --mode sheet` 出 4 张定妆照候选
3. 人工挑 1 张，裁成 `front.png` / `three_quarter.png` / `profile.png`
4. 再出 2-3 张表情图（微笑/落泪/惊讶）
5. 做风格锁校准（3 张不同场景，确认画风一致）

**复用角色**：直接从角色卡复制 `【IDENTITY LOCK】` 和 `【STYLE LOCK】` 到分镜脚本，
生图时把 `C00X_素材/` 传给 `--refs`。

## 目录约定

```
角色资产库/
├── README.md
├── C001_图书管理员.md          角色卡
├── C001_素材/
│   ├── sheet_cand_01..04.png   定妆照候选（挑完可删）
│   ├── front.png               ★ 三视图裁出的正面
│   ├── three_quarter.png       ★ 四分之三侧
│   ├── profile.png             ★ 正侧
│   └── emo_smile.png …         表情图
└── C002_...
```

打星的三张 + 表情图构成"角色资产包"，每张分镜从包里挑 2-3 张当参考图。

## 三条不能省的规矩

1. **【Mark】唯一识别特征必填**（痣/疤/雀斑/眼镜/耳钉）。这是模型唯一能牢牢抓住的钩子，
   没有它的角色一定会漂。
2. **【Wardrobe】标志性配饰颜色写死**。同理。
3. **定妆照用最贵档位**（Nano Banana Pro 4K，约 ¥1.7/张）。
   一次投入全片受益，不要在这里省钱——分镜才是该省的地方。

## 一条容易忘的

**只锁角色不锁风格是常见错误。** 结果 12 张图人是同一个人、画风各异，比人脸漂移更毁片。
每个角色卡都必须有 `【STYLE LOCK】`，且同一系列内容里逐字一致。

详见 `91_知识库/K5_生图一致性手册.md`。
