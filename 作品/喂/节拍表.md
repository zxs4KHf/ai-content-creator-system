# 《喂》节拍表

3 分整，16:9，1920×1080，成片 60fps。120 BPM，4 拍一小节，共 90 小节。

## 全片装置

- **主角**：一个“喂”字。全片不换位置，只换材质：空气、墨、泥、烟、电码、电流、比特、光、向量。
- **开头的谜**：黑屏出现 24 位数字，不解释。结尾揭晓：这就是“喂”。
- **第二层谜**：片子前半只讲打招呼的“喂”。到模型章才揭开另一个意思：喂养。
- **主线**：这个字一路在换身体。每一代都解决上一代的缺陷，也丢掉一点东西。
  - 声音走不远，还留不住。
  - 文字留得住，却只有一份。
  - 印刷能复制，却走得慢。
  - 烽火快，却说不了话。
  - 电报又快又能说，但声音没了。
  - 电话把声音找回来了。
  - 比特让所有东西变成同一种东西。
  - 光把距离几乎抹掉。
  - 模型第一次让这个字有了回应，但对面没有人。
- **固定版式**：左下角年份，右下角“现在它是：×××”，底部中央一行字幕。三处的位置和字号全片不变。

## 节奏

| 段落 | 感觉 | 用法 |
| --- | --- | --- |
| 开场、声音 | 慢，几乎没声音 | 让观众凑近听 |
| 文字、印刷 | 渐快 | 印刷章第一次踩满每一拍 |
| 烽火 | 宽阔 | 全片第一个大场面 |
| 电报、电话 | 机械、密 | 节奏最碎，电话接通时突然停一拍 |
| 比特、光纤 | 最快 | 光纤 66 毫秒是全片最快的一下，之后静默两小节 |
| 模型 | 冷，反转 | 全片的尤里卡 |
| 回答 | 空，只剩打字声 | 😊 和 👋 是全片唯一的笑点 |
