# 素材生成（阶段③上半）

## 这个 skill 解决什么

把 `02_分镜脚本.md` 里的提示词，变成 `素材/` 目录里可以直接进剪辑的图片和音频。

**一条铁律**：故事线插画走生图模型，知识线信息卡片走 HTML 排版截图。**扩散模型画中文字永远是残的**，不要试。

## Step 0：先读

1. `02_分镜脚本.md` —— 提示词来源
2. `91_知识库/K5_生图一致性手册.md` —— 一致性机制与模型选型
3. `91_知识库/K10_中文语音技术路线.md` —— 涉及配音时读取
4. `00_账号定位/角色资产库/` —— 角色是否已有定妆照

## 分支 A：故事线插画

### A1. 角色是否有定妆照？

**没有 → 先做定妆照，这一步不能省。** 见 K5 第三节的 7 步工作流。

```bash
cd 92_工具箱
python gen_images.py --mode sheet \
  --character ../00_账号定位/角色资产库/C001_xxx.md \
  --out ../00_账号定位/角色资产库/C001_素材/ \
  --n 4 --model pro --size 4K --ratio 16:9
```

出 4 张，**让用户挑 1 张**（这是唯一值得打断用户的生图环节），然后裁成 front / three_quarter / profile 三张独立图存入角色资产库。

定妆照用最贵档位（Nano Banana Pro 4K，约 ¥1.7/张）。**一次投入全片受益，不要在这里省钱。**

### A2. 风格锁校准

用同一段 STYLE LOCK 生成 3 张完全不同的场景（室内/室外/夜景），确认画风一致。
不一致 = STYLE LOCK 写得不够具体，**回去补细节再继续**，不要带着漂移的风格锁批量出图。

### A3. 批量出分镜

```bash
python gen_images.py --mode shots \
  --script "../02_制作中/2026-07-26_故事线_xxx/02_分镜脚本.md" \
  --refs ../00_账号定位/角色资产库/C001_素材/ \
  --out "../02_制作中/2026-07-26_故事线_xxx/素材/" \
  --model flash --size 2K --ratio 9:16
```

**滚动锚定**：脚本已实现——每出一张满意的分镜就加入参考池、替换最早的一张，让风格沿片子自然演进而不是突变。

### A4. 挑图与补图

出图后**必须人工过一遍**，常见问题：手指、文字乱码、角色漂移、构图越界。

- 单张不满意 → `--redo 5` 重出第 5 镜（会自动带上已通过的邻近镜作参考）
- 反复出不好的关键镜 → **转 GPT 网页手动补**：在同一会话内连续生成，让它"参考上一张的角色和风格"。GPT 的角色一致性官方承认不稳定，所以只用来补 1-2 张，不跑全片。

## 分支 B：知识线信息卡片

用 HTML/CSS 排版 + 无头浏览器截图。文字 100% 锐利、零 API 成本、完全可重复。

三种尺寸一次覆盖：
- `1080×1440` (3:4) —— 小红书
- `2100×900` (21:9) —— 公众号头图
- `1080×1080` (1:1) —— 通用分享卡

**六条硬校验**（生成后自动跑，任一不过就重排）：
1. 溢出：内容不得越出卡片边界
2. 字号封顶：字重/字号组合必须匹配预设
3. 页脚碰撞：正文不得压到页脚
4. 四带密度：画布横切 4 带，每带必须有内容或**有意留白**（防头重脚轻）
5. 截图 frame 溢出
6. 风格身份：极简风字重 ≥700 触发警告

**一条设计铁律：只允许选预设主题，禁止自定义 hex 色值。** 这是防止 AI 审美崩坏最有效的一招。

长内容分页四种模式：`separator`（用 `---` 手动分页）/ `auto-fit`（固定尺寸缩放）/ `auto-split`（按高度切多卡）/ `dynamic`（内容自适应）。微故事长度不定时用 `auto-split` + `separator` 混用。

## 分支 C：配音

```bash
cd 92_工具箱
python tts_batch.py --script "../02_制作中/xxx/02_分镜脚本.md" --out "../02_制作中/xxx/素材/audio/"
```

**edge-tts 只作内部基线/应急回退**。当前女声盲测基线：

| 音色 | 性别 | 官方标签 | 适用 |
|---|---|---|---|
| `zh-CN-XiaoxiaoNeural` | 女 | Warm | 中文温柔基线；中英混读单独验收 |
| `zh-CN-XiaoyiNeural` | 女 | Lively | 年轻活泼基线；警惕卡通腔 |
| `en-US-AvaMultilingualNeural` | 女 | Expressive/Caring | 中英混读基线 |
| `en-US-EmmaMultilingualNeural` | 女 | Conversational | 中英混读基线 |

**起手参数**：
- 平静叙述 `--rate=-10% --pitch=-2Hz`
- 悬疑铺垫 `--rate=-15% --pitch=-5Hz`
- 温柔治愈 `--rate=-8% --pitch=+0Hz`
- 反转揭晓 `--rate=+0% --pitch=+2Hz`

⚠️ **负值必须用等号**：`--rate=-10%` 对，`--rate -10%` 会报错。

**三个必须知道的限制**：
1. edge-tts **不支持多情感 style**（中文音色元数据里没有 StyleList 字段），情绪只能靠 rate/pitch 和分段
2. **SSML 已被移除**，`<break>` 不可用 → 停顿靠**分段合成 + 插静音**（脚本已实现），或用中文标点（强度 `，` < `。` < `……` < `——`）
3. 有 **403 速率限制** → 脚本已设并发 ≤2、间隔 1.5 秒。批量时不要调高

**edge-tts 的当前价值**：词级时间戳与链路已验证。但第三方无 Key 批量商用授权/SLA 不明确，不作为长期商用默认。

新女声路线按 K10：先用 `T10_语音盲测基准.txt` 盲测；本地优先 Qwen3-TTS 0.6B 的 `Serena`（温暖柔和）与 `Vivian`（明亮稍锐），两者官方均支持中文/英文但建议母语发挥；VoxCPM2 用原创声音设计作为 8GB 边界候选；云端只在用户配置正式密钥与预算上限后测试 Qwen3-TTS/CosyVoice。所有新路线先产影子版，不覆盖已通过旁白。

## 并行调度

| 环节 | 并行 | 说明 |
|---|---|---|
| 12 张分镜生图 | ⚠️ 受限并行 | API 有速率限制，脚本内并发 3-4，**不要开 12 个 subagent 各自调 API** |
| 定妆照 4 张候选 | ✅ 并行 | 一次调用出 4 张 |
| 配音分段 | ⚠️ 并发 ≤2 | edge-tts 403 限制 |
| 生图 + 配音 + 卡片 | ✅ 三条线并行 | 互不依赖，可同时跑 |
