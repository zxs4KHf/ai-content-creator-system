# 内容生产（阶段②）

## 这个 skill 解决什么

把一条选题变成**可以直接拿去生成素材的完整脚本包**。产出四份文件，一次做完，停在 G2。

## Step 0：先读这些（不可跳过）

1. `00_账号定位/账号定位.md` —— 人设、语气、红线
2. `91_知识库/K1_钩子公式库.md` —— 钩子必须从 17 种里选，标注编号
3. `91_知识库/K3_叙事结构模板.md` —— 结构必须从模板里选，标注编号
4. `91_知识库/K5_生图一致性手册.md` —— 分镜提示词的拼装规则
5. `91_知识库/K6_AI合规红线.md` —— 生成时自动规避
6. `91_知识库/K8_AI视频运动设计.md` —— 语义节拍、英雄镜、F0/K/F1 与降级
7. `91_知识库/K9_内容特征学习与账号矩阵实验.md` —— 实验元数据与原创边界
8. `00_账号定位/角色资产库/` —— 如果这条内容复用已有角色，读它的角色卡

## Step 1：建文件夹

命名：`02_制作中/YYYY-MM-DD_线_标题/`，线 ∈ { 知识线, 故事线 }。
例：`02_制作中/2026-07-26_故事线_最后一位图书管理员/`

## Step 2：产出 00_选题方案.md

用 `90_模板库/T1_选题方案模板.md`。要点：

- **钩子给 3 个备选**，每个标注 K1 编号（如 `B4 悬念提问`）。G2 时人只需圈一个。
- **结构标注 K3 编号**（如 `S-3 静物凝视`），并按模板展开起承转合。
- **差异化**一栏必须写清"同类内容大家怎么做、我们哪里不一样"，写不出来说明选题有问题，回 G1。
- **成本预估**要具体到"文案 X 小时 + 生图 Y 张 + 剪辑 Z 小时"。
- 若属于矩阵实验，写明栏目、experiment/hypothesis ID、唯一主变量和固定项。
- G1 同时评估 3 个关键视觉 moment、动画成本层级和失败回退后题目是否仍成立。

## Step 3：产出 01_故事文本.md 或 01_内容正文.md

- **故事线**：完整微故事。温暖、克制、留白，金句收尾，不说教。目标朗读时长按分镜倒推（60 秒片约 220-260 字口播）。
- **知识线**：先结论后过程。能一张图讲清就不用三段话。所有事实、数字、产品名标注来源；拿不准的写"待核实"。

**人设检查**：第一人称"我"，真诚不装，可以暴露失败过程。

## Step 4：产出 02_分镜脚本.md（最关键的一份）

用 `90_模板库/T2_分镜脚本模板.md`。

### 4.1 先写全局风格块

- **画幅**：抖音/视频号 9:16；小红书 3:4；B站封面 16:9
- **STYLE LOCK**（英文风格后缀）：所有分镜**原样复用，一个字不改**
- **CHARACTER LOCK**（每个角色一段）：从角色资产库复制；新角色则新建角色卡（见 Step 4.4）
- **CLUE**：故事里反复出现的物件，登记固定描述

### 4.2 分镜表

先按“观众此刻新知道了什么”拆 `HOOK / SETUP / ESCALATE / TURN / PAYOFF / ECHO` 语义节拍，再决定镜头数。起步可为 8–12 镜、60–90 秒，但不是硬配额。

硬规则：
- **镜 1 必须承担钩子**，且前 3 秒无自我介绍、问候、Logo、空镜
- 镜头时长服从真实旁白和信息状态；明显长于相邻镜时写停留理由，不用固定秒数机械切镜
- **字幕 ≠ 口播**：字幕只放最关键的短句，**每行 ≤12 字，最多 2 行**
- 最后一镜是金句定格，金句 ≤15 字且可单独截图
- 每镜写 `INTENT` 与方法；最多 2–3 个英雄镜。复杂接触/遮挡/重心变化用 `T8_运动镜头卡` 写 `F0→K→F1`
- 主体、环境、摄影机分栏；确定性 animatic 必须在随机视频生成失败时仍完整成立

### 4.3 生图提示词按三段拼装（顺序不能变）

```
[IDENTITY_LOCK]  角色锁，声明"和参考图是同一个人"，并列出要保留的特征
[SCENE]          本镜独有：场景 + 景别 + 机位 + 光线 + 动作
[STYLE_LOCK]     风格锁，原样复制
```

**绝对禁止在提示词里用代词**（her / it / the character）。写 `The woman with shoulder-length black hair`，不写 `her`。

分镜生图提示词可以**并行 fan out**：每 3-4 镜一个 subagent 写，主 Agent 负责统一 STYLE LOCK 与 IDENTITY LOCK 的逐字一致性（这一步必须主 Agent 做，subagent 之间会各写各的）。

### 4.4 新角色则建角色卡

存 `00_账号定位/角色资产库/C00X_角色名.md`，用 `90_模板库/T5_角色卡模板.md`。定妆照生成后把图也存进去。**角色资产是跨内容复用的，一次投入长期受益。**

### 4.5 口播全文

把分镜口播连起来通读，检查节奏与口语化，标注朗读约多少秒。**自己念一遍，拗口就改。**

## Step 5：产出 04_评审单.md 的 G1/G2 部分

用 `90_模板库/T4_评审与数据复盘模板.md`。**AI 先自检并给出结论**，人只需要打勾或写一行意见。

G2 自检清单（逐条勾，不能空着）：
- [ ] 钩子在前 3 秒成立，已标注 K1 编号
- [ ] 结构已标注 K3 编号且按模板展开
- [ ] 口播时长在目标区间（朗读实测约 __ 秒）
- [ ] 字幕与口播不重复、每行 ≤12 字、最多 2 行
- [ ] 生图提示词已按三段拼装，STYLE LOCK 逐字一致
- [ ] 提示词中无任何代词
- [ ] 金句 ≤15 字且可单独截图
- [ ] 红线自查通过（K6：事实/敏感/价值观/违禁词）
- [ ] 语义节拍、连续性账本和英雄镜预算已冻结
- [ ] 外部样本未作为改写底稿，原创差异审计通过

## Step 6：停在 G2

汇报格式：

```
《标题》已做到 G2。文件夹：02_制作中/xxx/

钩子 3 选 1：
  A. [B4 悬念提问] ……
  B. [B5 视觉冲击] ……
  C. [B7 高能片段] ……

结构：S-3 静物凝视 ｜ 12 镜 ｜ 口播约 78 秒 ｜ 需生图 12 张
角色：复用 C001 / 新建 C003（已建角色卡）

G2 自检：8 项全过 / 第 X 项存疑：……

请圈一个钩子，并说"G2 通过"或给修改意见。
```

**汇报后停下等人。**

## 并行调度

| 环节 | 是否并行 | 说明 |
|---|---|---|
| 3 个钩子备选 | ✅ 并行 | 各一个 subagent，用不同钩子类型，避免同质 |
| 正文创作 | ❌ 串行 | 需要整体节奏感，拆开会散 |
| 分镜生图提示词 | ✅ 并行 | 每 3-4 镜一个 subagent |
| 一致性校对 | ❌ 主 Agent | STYLE/IDENTITY LOCK 的逐字比对必须集中做 |

## 质量自检

- [ ] 四份文件都产出了，无占位符残留（搜 `___` `TODO` `待补`）
- [ ] 全片 STYLE LOCK 逐字一致（用 diff 心态比对，不是"看起来差不多"）
- [ ] 每镜提示词都有 IDENTITY_LOCK 且无代词
- [ ] 新角色已建角色卡
- [ ] G2 自检 8 项逐条勾选，存疑项写明
- [ ] `endpoint_binding` 如实填写，prompt_only 未冒充实际末帧锁定
