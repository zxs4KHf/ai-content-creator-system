### 逐镜画格合同

| image | panel_role | focus `{x,y,w,h}` | action_state | keyframe_role | 信息功能 | impact 预算 |
|---|---|---|---|---|---|---|
| | full/detail/impact | 仅 detail 可填 | static/initial/development/final | context/setup/bridge/endpoint/hold/evidence | | |

- `full` / `impact` 必须完整保留源画面；`detail` 也必须保留上下文全格，显式 focus 只生成第二证据格。
- focus 为 0–1 归一化坐标，宽高 ≥0.08，禁止越界和自动钳位；impact 必须声明预算，超预算直接退回。
- 对应关系：`initial → setup`、`development → bridge`、`final → endpoint/hold`、`static → context/evidence/hold`。

## 四、同片实验

- **固定项**：故事、旁白、字幕、时长、封面承诺、发布窗口
- **唯一变量**：全幅插画 / 漫画画格（任选一项）
- **观察**：3 秒留存、平均观看时长、关键反转前后曲线、有效评论
- **失败判据**：只增加视觉噪声；字幕遮挡；反转提前泄露；观看提升来自时长/声音等混杂变量
- **结论**：保留 full / 保留 comic / 继续 shadow / 淘汰
