# 外部样本特征卡

> 只学习“为什么有效”，不保存或复制作品表达。每个样本只能产出一个待验证假设。

## 一、溯源

- **sample_id**：EXT-平台-YYYYMMDD-___
- **source_url**：
- **creator**：仅溯源，不进入生成提示词
- **observed_at / sample_window**：
- **公开信号**：带采样时间；后台不可见项留空
- **rights_notes**：仅观察不可使用 / 自有 / 已授权 / 公版待核验

禁止下载视频、保存完整字幕/逐字稿、截取封面/原画/配乐或把脚本交给模型改写。

## 二、抽象功能

- **audience_promise**：观众为什么点开、看完或分享？

- **title_mechanism**：反常识 / 信息缺口 / 两难 / 结果前置 / 其他

- **opening_0_3s.language_function**：只写功能，不摘抄原句
- **emotion_trigger / information_gap**：
- **conflict**：主角的目标、阻力、代价（只写抽象关系）
- **causal_steps / turn_timing**：升级次数与相对时间
- **payoff_type / ending_function**：
- **shot_grammar**：景别变化、方向、进入/转向/减速/定格的功能
- **audio_function**：节奏、停顿、环境声功能；不复制旋律或声线
- **duration_and_density**：总时长、镜头数、每 10 秒信息节点数
