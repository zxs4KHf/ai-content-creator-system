## 诊断（按 K4 的七步顺序，不要跳步）

```
① 有没有曝光？        →
② 有曝光，留不住人？  →
③ 留得住，看不完？    →
④ 看得完，不点赞？    →
⑤ 点赞了，不评论？    →
⑥ 点赞了，不转发？    →
⑦ 都不错，不涨粉？    →
```

**定位结论**：卡在 ____ 环，对应 K4 诊断表的 ____ 行。

> ⚠️ 归因铁律：内容质量 80% / 账号 5% / 发布时间 5% / 未知 10%。
