## 二、三个首轮方向

每个方向先做 2 个 seed，共 6 个候选；先盲选声线，再做表演渲染。不要同时改声音人格和表演强度。

### S1 · 温暖故事声

```text
年轻成年女性，中低音区，温暖克制，略有自然气息但咬字清楚。像在安静房间里只对一个人讲故事，亲近而不撒娇；句尾自然落下，不拖长。禁止播音腔、客服腔、广告微笑、刻意卖萌和持续气声。
```

### S2 · 清醒悬疑声

```text
年轻成年女性，音色干净，能量偏低，注意力集中。停顿只服务于线索和信息变化；疑问处收紧而不是简单升调，紧张感逐步增长后释放。禁止故作深沉、每句压低、机械慢速和夸张惊吓。
```

### S3 · 明亮知识声

```text
年轻成年女性，自然、有亲和力、思路清楚，节奏略快但不赶。关键数字和专名轻重音明确，英文短语保持自然连读；语气像解释给聪明朋友听。禁止新闻播报、广告腔、客服微笑和等时长断句。
```

## 三、逐段导演块

按语义和情绪状态切成约 8–20 秒一块，不按固定字数硬切。每块填一张：

```text
VOICE_ASSET_ID:
INTENT: 这一段希望听众感到什么
SUBTEXT: 说话者知道但没有直接说出的东西
ENERGY: 1–5，并写起点 → 转折 → 终点
PACE: 自然 / 偏慢 / 偏快；为什么
PAUSE: 只标关键停顿与目的，不在每个逗号停
EMPHASIS: 最多 2 个真正承载信息变化的词
ENDING: 句尾如何收束
FORBID: 本段最容易出现的 2–4 个 AI 失败模式
```

## 四、生成与淘汰

1. 同稿、同响度、无后期，候选名随机化；基准文本固定为 T10。
2. 普通段每块 2 seed；只允许英雄句增加到 3 seed，不无限抽卡。
3. 先淘汰错读、漏字、节奏模板化和英文失败，再比较音色偏好。
4. 入围声音必须保存 prompt、seed、模型 revision、许可快照、WAV hash；不得只保留“最好听那一条”。
5. 入围后再做 100 个短段稳定性门和 10 条影子运行；未过门不替换现有音频。
6. 后期只做轻量去齿音、必要 EQ/压缩、响度与 true peak 统一；不能用重度降噪、混响或变调掩盖生成缺陷。

## 五、双语处理

- 英文整句显式指定 English；中英混读同时测试自动语言与显式分块两条路线。
- 保持同一声音资产和响度，不用完全不同的中文/英文音色拼成“多语”。
- 专名先建发音词典；英文重音或连读不自然就重生成该语义块，不拉伸整段补救。
- 最终按 T9 单列“英文听感”，中文优点不能抵消英文失败。
