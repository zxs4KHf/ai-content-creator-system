# 分镜脚本：《标题》

> AI 在方案确定后填写，存为 `02_分镜脚本.md`。
> 起步基准：**8–12 镜、口播 60–90 秒**，但镜头必须按信息状态变化拆分，不设统一的 3–6 秒硬规则。
> 依据：`91_知识库/K5_生图一致性手册.md`、`K8_AI视频运动设计.md`

## 一、全局风格块

**画幅**：抖音/视频号 9:16 ｜ 小红书 3:4 ｜ B站封面 16:9

### 【STYLE LOCK】
> 所有分镜**原样复制，一个字都不改**。这是画风一致性的唯一保障。

```
Style: soft gouache children's-book illustration, warm muted palette of dusty blue and amber,
visible paper grain, clean confident line work, gentle rim light,
cinematic vertical composition with generous negative space at the top.
No text, no watermark, no signature, no logo.
```

### 【CHARACTER LOCK】
> 每个角色一段。已有角色从 `00_账号定位/角色资产库/C00X_*.md` **原样复制**；
> 新角色在这里写完整，同时新建角色卡（用 T5 模板）。

```
CHARACTER A —— 【角色名】
Identity :
Face     :
Hair     :
Mark     : ★唯一识别特征，一致性的锚，必填
Wardrobe :
Build    :
```

### 【CLUE】线索物件
> 故事里反复出现的物件（伞/猫/杯子）。**物件比人脸更容易保持一致，且是叙事的锚。**
> 每次出现的描述必须完全相同。

| 物件 | 固定英文描述 | 出现在哪几镜 |
|---|---|---|
| | | |

### 【NEGATIVE】
> Gemini **没有负面提示词参数**，要把负面写成正向陈述
> （`her hands are relaxed and clearly visible with five fingers` 优于 `no extra fingers`）。
> 本地 SD/Qwen 才用真正的负面框。

```
Avoid: extra fingers, deformed hands, multiple people, changed hairstyle,
different clothing, photorealistic skin, harsh contrast, text overlays, borders.
```

## 三、分镜表

> **拼装规则**：每镜提示词 = `[IDENTITY_LOCK] + [SCENE] + [STYLE_LOCK]`，顺序不能变。
> **提示词里绝对不能出现代词**（her / it / the character），一律用具体描述替代。
> **SCENE 必须含 5 要素**：场景 + 景别 + 机位 + 光线 + 动作。
> 镜 1 必须承担钩子。字幕 ≠ 口播，字幕每行 ≤12 字、最多 2 行。

| 镜号 | beat_id | INTENT（看完发生什么变化） | 画面描述 | 口播文案 | 屏幕字幕 | 时长/停留理由 | 方法 | 生图提示词（英文，纯提示词不要加注记） |

## 六、G2 生图与运动自检（K5/K8）

- [ ] 角色资产库里有该角色的定妆照（三视图 + ≥1 张表情图）
- [ ] 全片 STYLE LOCK 逐字一致（用 diff 心态比对，不是"看起来差不多"）
- [ ] 每镜提示词按三段拼装
- [ ] 提示词中**无任何代词**
- [ ] 反复出现的物件已登记为 CLUE，各镜描述完全一致
- [ ] 画幅正确
- [ ] 知识线信息卡片走 HTML 排版，**没有让扩散模型写中文字**
- [ ] 未使用真人肖像、未模仿在世艺术家署名风格
- [ ] 每个镜头关联一个语义节拍与明确 `INTENT`，没有按标点或固定秒数机械拆镜
- [ ] 英雄镜不超过 2–3 镜，且已为复杂接触/遮挡/重心变化设计 `F0 → K → F1`
- [ ] 主体、环境、摄影机运动已分开；每镜最多一个强运动通道
- [ ] `endpoint_binding` 如实记录；`prompt_only` 未冒充实际末帧约束
- [ ] 确定性 animatic 能独立成立，动态生成失败时有明确回退
- [ ] 连续性账本覆盖人物方向、视线、道具、光线和镜头边界
