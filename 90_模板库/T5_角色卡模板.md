## 【CHARACTER LOCK】

> 生图时**原样复制**这一段。填写要求：每项一个形容词，不要堆砌。

```
Identity : （年龄段 / 性别 / 气质，一句话）
Face     : （脸型 + 眼型 + 眉 + 鼻 + 唇）
Hair     : （长度 + 发型 + 颜色 + 刘海）★ 头发是漂移重灾区，必须精确
Mark     : （1-2 个唯一识别特征：痣 / 疤 / 雀斑 / 眼镜 / 耳钉）
Wardrobe : （上衣 + 下装 + 鞋 + 1 个标志性配饰，颜色写死）
Build    : （身高体态，1 个词）
```

> **【Mark】和【Wardrobe 标志配饰】是模型唯一能牢牢抓住的"钩子"。**
> 没有钩子的角色一定会漂。这两项不能省，也不能写得含糊。

```
Keep the facial features, hairstyle and outfit completely unchanged.
```
