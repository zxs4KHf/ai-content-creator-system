## 二、状态与因果

- **START_FRAME (F0)**：
- **KEY_POSE (K)**：无 / 接触成立 / 遮挡边界 / 重心完成 / 方向反转 / 身份锚点 / 其他
- **END_FRAME (F1)**：
- **动作链**：`TRIGGER → PERCEIVE → PREPARE → EXECUTE → SETTLE`
