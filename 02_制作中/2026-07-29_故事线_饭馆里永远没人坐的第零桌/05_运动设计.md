# 运动设计：《饭馆里永远没人坐的“第零桌”》

> G2 规划稿。当前没有正式画面、真实音频或任何 I2V/V2V 输出；所有镜头都先以静帧 / Ken Burns 完整成立。动态升级只允许作为可删除的影子候选。

## 一、基线决策

- **叙事单位**：6 个核心因果状态展开为 10 个视频镜头；拆分只为区分空间、证据与动作状态。
- **确定性基线**：静帧 + 硬切/短溶解 + 3%–5% Ken Burns；镜头末段约 18% 停稳，实际值以真实旁白和字幕可读性复核。
- **画格预算**：7 full / 2 detail / 1 impact；impact 只给镜 10。
- **英雄镜预算**：2，只有镜 7 与镜 10；同配置连续失败 2 次即回退，不盲抽。
- **K12 路由**：`REUSE_POTENTIAL=人物低 / 场景与账本语法中`，`ASSET_TIER=静帧/2D`，`HERO_MOTION=镜7、镜10`。不建 3D、rig、年龄或服装变体。
- **末帧事实**：当前统一 `endpoint_binding=not_applicable`。未来只传首帧时标 `prompt_only`；只有 F1 真正进入模型末帧槽才可标 `actual_last_frame`。
- **文字分轨**：账本文字、点单备注与老板姓名全部在后期 typography track 完成；生成式视频不得负责中文书写。

## 三、英雄镜 7：漏看备注

- **INTENT**：观众必须看清老板不是故意无视，而是手指在忙乱中遮住备注；这只解释错误，不替老板免责。
- **F0**：点菜单平放在操作台，右上角备注区完整可见，老板右手尚未接触。
- **K**：右手五指与票据边缘接触成立；票据不穿手、不折断、不改变尺寸。
- **F1**：老板抬起票据，右拇指恰好覆盖右上角；其余四指可见，右护袖不变，末段停稳。
- **BODY**：来单触发 → 视线扫到票据 → 手掌展开 → 指尖接触 → 抬起 → 拇指遮挡 → 手腕落稳。
- **FACE / EYES**：只需短暂看向票据，不做夸张惊讶或喜剧表情；脸部不是本镜焦点。
- **CAMERA**：操作台侧前方近景 → 锁机 → 票据轻微进入中心 → 无环绕/变焦 → ease-out → F1 停稳。
- **CONTACTS**：右手—票据；票据—操作台由接触变为分离。必须检查接触前 / 成立 / 分离后三态。
- **SECONDARY**：厨房热气强度 1；其他人物、锅具、菜盘完全锁死。
- **METHOD**：先用 F1 静帧。若升级，优先有 F0/K/F1 的关键帧或动作底片 V2V；单首帧随机 I2V 不得声称末帧受控。
- **FALLBACK**：F0 票据全露 → 硬切 F1 拇指遮挡；用一次纸张轻响作为动作标点。
- **一票否决**：多指/少指、票据变形或换字、左右手互换、护袖消失、备注角漂移、摄影机越轴、动作未落稳。

## 四、英雄镜 10：责任栏落名

- **INTENT**：老板接受与其他人相同的记录；价值由一笔完成，不靠旁白说教。
- **F0**：责任栏空白，黑铅笔在纸面上方约一个笔尖距离，橄榄色右护袖清楚。
- **K**：笔尖与纸面接触，食指/拇指/中指握笔关系稳定，手腕重心落到桌面附近。
- **F1**：短距离书写结束，手与笔停稳；老板姓名由后期排版/遮罩轨显现，不由视频模型生成。
- **BODY**：看到空栏 → 手腕前移 → 笔尖接触 → 短距离横向书写 → 笔尖停 → 手腕落稳。
- **FACE / EYES**：画外，不承担表演。
- **LIPSYNC**：无对白口型；旁白是画外音。
- **CAMERA**：责任栏极近景锁机，不推拉、不环绕、不拉焦；主体动作是唯一强通道。
- **CONTACTS**：手—笔保持，笔尖—纸面由无接触到接触；纸张—桌面始终锁死。
- **SECONDARY**：无环境运动；不加风、蒸汽、衣摆或景深呼吸。
- **TYPOGRAPHY TRACK**：姓名、桌号、金额与责任栏标题均后期排版；文字出现必须与笔尖路径和停顿同步，但不伪装成模型原生可读文字。
- **METHOD**：确定性基线用两张静帧 + 文字遮罩。只有手部样片明显更好且五点/接触帧全过，才替换为首尾帧或 V2V。
- **FALLBACK**：空白责任栏停 0.4 秒 → 落笔音 → 已写责任栏停 1 秒。
- **一票否决**：手指融合、笔穿纸、笔长度变化、纸面纹理漂移、生成乱码、姓名错位、落笔前先出现姓名、末帧仍在运动。

## 六、资源、重试与停止条件

- 静态基线不需要本地视频模型，不占用当前 GPU 进程，也不等待 3D/rig。
- G2 通过后先做 6 帧灰度图和无旁白测试；不通过则退回因果/构图，不先加配音、运镜或更多画面。
- 英雄镜每镜最多 2 次同配置尝试；第二次仍有手部、票据或接触问题时，改变一个变量或直接回退。
- 不因已花算力接受坏镜；动态镜必须明显优于静态基线才可替换。
- 正式 `motion_plan.json` 暂不创建：真实图片名、音频时轴与最终镜长均未冻结，提前生成会伪造生产状态。G2 通过后从本文件生成并校验。
