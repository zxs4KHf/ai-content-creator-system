# 运动设计：《最后一位图书管理员》

> 按 `91_知识库/K8_AI视频运动设计.md` 执行。当前 G3 候选使用确定性 Ken Burns 基线，已经能完整表达故事；镜 4、6、10 仅是后续 A/B 的英雄镜候选，**尚未替换进本次成片，也不会在用户 G3 评审前改变现有候选**。

## 一、基线决策

- **语义拆镜**：原镜 3 同时承担“日常擦书”和“拒绝关闭建议”两个信息状态，已拆为 3A/3B；其余镜头各承担一个主要视觉问题。
- **确定性基线**：11 张图 + 真实旁白时轴 + Ken Burns；每镜最后约 18% 停止运动。
- **英雄镜预算**：最多 3 镜；当前候选 4（回望）、6（递书接触）、10（开门揭示）。
- **动态替换门槛**：五点与接触帧 QA 全过，且观感明显优于当前基线；否则保留基线。
- **末帧事实**：当前没有任何 I2V 调用，全部 `endpoint_binding=not_applicable`。未来若只写提示词而未把 F1 传入末帧槽，必须标 `prompt_only`，不得写“已锁末帧”。

## 二、逐镜计划

强度为 `S 主体 / E 环境 / C 摄影机`，范围 0–3。

| 镜 | INTENT | F0 → K → F1 | 动作/环境因果 | CAMERA 六项摘要 | S/E/C | 基线 / 回退 |
|---|---|---|---|---|---|---|

| 2 | 突出旧馆在新城中的孤立 | 高楼与旧馆同框 → 无 → 唯一暖窗成为重心 | 叶片落定；建筑与窗锁死 | 高位远景→tilt/downward drift→不跟随→旧馆居中→减速→停 | 0/0/1 | 向下平移 / 静帧 |
| 3A | 让林伯的日常劳动先成立 | 手在书脊一端 → 无 → 擦拭完成、手停 | 动作只由画面暗示；基线不生成手部运动 | 书架侧向中景→右移→不跟随手→找到林伯→减速→停 | 0/0/1 | 向右平移 / 静帧 |

| 8 | 建立两人相互理解 | 两人隔灯而坐 → 无 → 双人平衡对望 | 女孩发问→林伯抬眼/微笑仅由静态目标表达 | 女孩肩后中景→dolly in→不越轴→双人平衡→减速→停 | 0/0/1 | 轻推近 / 静帧 |

## 四、英雄镜实验卡

真正升级时，为镜 4、6、10 分别复制 `90_模板库/T8_运动镜头卡.md`，并遵守：

1. 镜 4 只测试“眼睛→头肩→站稳”的回望，摄影机保持微动；不做绕拍。
2. 镜 6 必须有接触成立 K；优先首尾帧拆段或有动作底片的 V2V，失败两次退当前静帧。
3. 镜 10 必须处理门的遮挡边界与重心转移；优先 `F0→K`、`K→F1`，不得一次生成“推门+跨步+绕拍+拉焦”。
4. 每次只改一个变量，检查 0/25/50/75/100% 和所有接触/遮挡帧。
5. 本次 G3 候选不等待这些实验；动态升级是后续同片 A/B 素材，不是发布阻塞项。

## 五、运动计划文件

`素材/motion_plan.json` 使用 schema v2：

- `subject_motion / environment_motion / camera_motion` 分栏；
- `hero_candidate` 与 `hero_shot_budget` 防止全片盲目升级；
- `method / endpoint_binding / fallback` 明确当前实现与降级；
- `camera_motion.mode / amount / ease / settle_ratio` 保持现有成片的确定性参数。

`build_video.py --motion-plan` 同时兼容旧版扁平 JSON 和新版字段，并验证强运动通道、英雄镜预算和末帧声明真实性。
